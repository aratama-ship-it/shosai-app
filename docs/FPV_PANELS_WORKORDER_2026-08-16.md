# 発注書: 視界モードに正面図・平面図の浮動小窓を足す（2026-08-16・第2便）

- 発注: Claude（仕様・検証担当）→ Codex（実装担当）
- 前提: `docs/FPV_WORKORDER_2026-08-16.md`（第1便・実装済み commit 4abd463）を先に読む
- 本人要望: 視界モードの中で**正面図と平面図も見たい**。両図とも**ドラッグで位置を変え、
  サイズも変えられる**こと。

## 1. 何を作るか

視界オーバーレイの上に「正面図」「平面図」の2枚の浮動小窓（パネル)を出す。
それぞれ、つかんで移動・角をつかんでリサイズ・個別に隠す/出すができる。
中身は**本体が描いている既存の正面図・平面図キャンバスをそのまま転写**する
（視界モード用に図を描き直さない。ラベル・照明・動線など本体と完全に同じ見た目になる）。

## 2. 方式（決定事項）

- `stage-sketch.js` から `open(ctx)` の ctx に次を追加:
  - `getFrontCanvas(): HTMLCanvasElement | null` … 本体の正面図キャンバス
  - `getPlanCanvas(): HTMLCanvasElement | null` … 本体の平面図キャンバス
- FPV側は毎フレーム（既存のrAFループ内で）`drawImage(srcCanvas, 0, 0, w, h)` で
  パネルのキャンバスへ転写する。srcが無い/幅0のフレームは静かにスキップ。
- 場面送り（stepScene）後に本体側の再描画が走ることを確認する。もし本体が
  「見えていないと描かない」最適化をしている場合は、ctxに `requestRedraw()` を足して
  stepScene後に呼ぶ（本体の既存の再描画関数を包むだけにする。新しい描画経路を作らない）。
- 転写はアスペクト比を保つ（srcのw:hをパネルに合わせ、letterboxはパネル背景色で埋める）。

## 3. UI仕様

- パネルの構成: 上辺にタイトルバー（「正面図」/「平面図」・右端に隠すボタン「−」）、
  下に転写キャンバス、右下角にリサイズハンドル（14px・`cursor: nwse-resize`）。
- 見た目は既存オーバーレイの流儀（`--chip` 背景・`rgba(232,226,212,0.16)` 枠・角丸3px・
  紙色文字）。タイトルバーは小さく（11px）。
- ドラッグ移動: タイトルバーまたはパネル余白をつかむ。リサイズ: 角ハンドルのみ。
  どちらも pointer events で、**必ず stopPropagation して視界の見回しドラッグと衝突させない**。
  タッチも同様。
- サイズ制約: 幅 160〜min(720, 画面幅の60%)。高さはアスペクト比から自動。
  位置は画面内にクランプ（はみ出し禁止。リサイズ後・ウィンドウリサイズ後も再クランプ）。
- 出す/隠す: ミニマップの下に小さなトグルチップ「正面図」「平面図」を縦に置く
  （押すたびに表示/非表示。表示中はチップをハイライト＝既存 `.chip.on` と同じ見た目）。
  パネルの「−」で隠したときもチップの状態を同期する。
- 初期配置: 両パネルとも**表示**。正面図は右上（ミニマップの左隣・幅280px）、
  平面図は右下（場面ナビの上・幅280px）。既存のHUD（タイトル・チップ列・ナビ・ミニマップ）
  と重ならない位置にする。
- 位置・サイズ・表示/非表示は `localStorage` キー `shosai-fpv-panels-v1` に保存し、
  次回開いたとき復元する（ショーのデータには何も書かない）。壊れた保存値は黙って初期値へ。
- 既存のミニマップ（視野の扇つき）は**そのまま残す**（役割が違う: 視線方向の表示）。

## 4. i18n

「正面図」「平面図」は既存キーを再利用する（`stage-i18n.js` を検索して確認）。
新規が必要なのは隠すボタンの aria-label 程度: 「この図を隠す」→ "Hide this panel"。
coverageテストの作法に従う。

## 6. テスト（`tests/stage-first-person.test.mjs` へ追加）

パネルのレイアウト計算を純粋関数に切り出し（`_panels` として公開）、次を検証:

1. クランプ: 画面外の位置・過大/過小サイズが範囲内へ収まる
2. アスペクト比: src 1600×900 でパネル幅280 → 高さ157〜158（タイトルバー分は別）
3. 保存/復元: レイアウト→JSON→復元の往復で一致。壊れたJSONは初期値
4. トグル: 隠す→出すで visible フラグとチップ状態が同期（DOMはFakeでよい）

既存テスト全通過: `node --test tests/*.test.mjs`
