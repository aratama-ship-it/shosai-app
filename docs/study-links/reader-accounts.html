無料演者アカウントと、PC・スマホの自分用メモ

2026-09-09 · ローカル実装と検証。Stage Sketch本家・ベータの共通機能。

Googleを前提に実装しています。Googleの実アカウント接続は設定未登録のため未確認です。本番デプロイ・秘密情報登録・外部への送信は行っていません。以下は専用のローカルテストアカウントで確認しました。

開いていた招待リンクを開く 受け取ったショーの一覧 English

元の8796番も最新コードへ更新し、既存のショーとリンクを保持しています。複数オーナー・端末同期の比較データは8800番の一覧にあります。両ポートは独立したローカル保存先です。

確認手順

  1. 招待リンクを開き、「演者 A / Reader A」を選びます。無料アカウントのローカル確認用です。
  2. 文章やペンの線を残し、「アカウントに保存済み」を確認します。別のブラウザでも同じ演者Aを選ぶと、同じ文章と線が戻ります。
  3. 別オーナーの招待を開くと同じ一覧に追加されます。演者Bを選ぶと別の自分用メモになります。
  4. 「この画面をオーナーへ共有」を押した内容だけを、表示名・場面・日時付きでオーナーに送ります。

オーナー画面: ベータ / 本家。ローカル専用ID study-owner、パスワード local-study-owner。別オーナーは study-other / local-study-other。実データ・実認証情報は使っていません。

実装した体験

  • 無料ログイン → 招待リンクを開く → 自分のショー一覧へ追加。複数の親（オーナー）に対応します。
  • 自分用メモと正面図・平面図のペンをアカウントに自動同期。共有するまで他の演者・オーナーには見せません。
  • 端末間の同時変更は両方を保持して選択を求めます。通信失敗時は同期待ちと表示し、端末に保留した内容を再接続時に送ります。
  • 旧バージョンの端末メモは明示的な引継ぎ操作で取り込みます。既存のショー保存キーへ書き込みません。
  • PCは正面図・平面図をそれぞれ全幅で縦に配置。日英、場面移動、再生、ペンUndo/消去を継承します。
  • オーナーは従来どおりスナップショットの発行・明示更新・失効・受信メモ/画像確認。編集中の変更は自動公開しません。

保存と認可

  • StudyLinks: 192bit招待トークン、公開スナップショット、明示共有したメモと画像。所有者操作は既存の認証済み作成者とサーバーで照合します。
  • StudyReaderAuth: OAuthの単回状態と不透明なセッションのハッシュ。Googleの署名・issuer・audience・有効期限・nonceを検証。PKCEとブラウザに結び付けたstateを使用します。セッションは7日、HttpOnly / SameSite=Lax、本番HTTPSではSecure。ログアウトでサーバー上のセッションも無効化します。
  • StudyReaderAccount: サーバー確認済みの本人IDごとに独立したSQLite Durable Object。所有者とショーIDから結び付きを決め、リンク再発行後も同じ本人ノートを保持。version照合と操作IDで競合と再送の重複を防ぎます。
  • 演者Cookieは編集ライセンスにはなりません。編集画面・資料棚・名簿・管理APIは開きません。開きっぱなしの旧アカウントのタブから、新アカウントへメモが混入しない照合も行います。
  • 本人ノートの安全上限: 100ショー、ショーごと500場面・2MiB、アカウント20MiB、本文2000字、64線×512点、毎分120更新。OAuth状態/セッションも件数・期限・作成頻度を制限。
  • IP/UA、Googleのaccess/refresh token、ショー内容の解析データは保存しません。共有・閲覧・ノート応答はprivate, no-store。公開静的資源は明示リストのみです。

認証実装の根拠: Google OpenID Connect、Google Web Server OAuth。実際のGoogle接続確認は、本番用設定登録後の別工程です。
