# 発注書 — 首を出す・肩を絞る（2026-08-16・肉付け第3便）

## 原因（実測で確認済み）

### 首が無い

`NECK_RINGS` は3枚しかなく、s は「肩の中点(y=0.82)→頭の中心(y=0.935)」の割合なので、
実際の高さは **y=0.841 / 0.883 / 0.918**。頭の楕円の下端が y≈0.870 なので、
**見える首の区間（y=0.841〜0.870）に細い断面が1枚も無い**。
結果、僧帽筋の halfX=0.084 から頭の中の 0.040 へ一気に補間され、
頭の付け根で半幅0.054（首幅18cm）になる。**首が頭（半幅0.0445）より太い。**

実測（MakeHuman・身長比）はその逆で、首のいちばん細い所は halfX 0.0377 / rz 0.0327、
僧帽筋の裾が 0.065〜0.078。**断面を足して、首の高さに細い所を作る。**

### 肩が大きい

肩関節 `shL`/`shR` が x=±0.115、そこへ腕の付け根の丸（半径0.029）が付くので
外形は ±0.144＝**肩幅0.288H（165cm換算で47.5cm）**。実測の肩幅は約0.245H（40cm）。
本人判断（2026-08-16）で**±0.115 と実測 ±0.100 の中間 ±0.1075 を採る**。

## やること（3箇所）

### 1. `NECK_RINGS` を3枚から5枚に増やす（1630行あたり）

```js
  const NECK_RINGS = [
    { s: 0.13, halfX: 0.072, rz: 0.040 },   // 僧帽筋の裾。ここを飛ばすと肩が角になる
    { s: 0.26, halfX: 0.048, rz: 0.036 },   // 首の付け根
    { s: 0.40, halfX: 0.037, rz: 0.034 },   // 首のいちばん細い所（実測 0.0377/0.0327）
    { s: 0.62, halfX: 0.035, rz: 0.040 },   // 顎の下・後頭部の付け根
    { s: 0.85, halfX: 0.034, rz: 0.046 },   // 頭の中まで差し込む
  ];
```

既存のコメント（軸を「肩の中点→頭」に沿わせる理由・抱え込み宙返りの話）は**そのまま残す**。
そのうえで、次の1行を既存コメントの末尾に足す。

```js
   * ★2026-08-16: 3枚では見える首の高さ(y≈0.84〜0.87)に細い断面が無く、頭より首が太かった。
   *   枚数を増やして首を作る。s=0.40 が実際に見える首の最細部。
```

### 2. `TORSO_RINGS` の肩まわりを絞る（1617行あたり）

該当2行だけを変える。他の4行は触らない。

```js
    { t: 0.00, halfX: 0.102, rz: 0.051 },    // 肩
    { t: 0.14, halfX: 0.095, rz: 0.060 },    // 肩の下。ここを飛ばすと脇が角になる
```

（腕の付け根の丸は中心 x=0.1075・半径0.029 なので内側の端は 0.0785。
胴の断面 0.102 より内側にあり、既存コメントの「付け根の丸が胴の外へ飛び出す」は起きない）

### 3. 肩関節の位置 ±0.115 → ±0.1075

**`shL: [-0.115, …], shR: [0.115, …]` の形になっている行だけ**、x を
`-0.1075` / `0.1075` に置き換える。y と z は**一切変えない**。

- 対象は22行（`BASE_JOINTS` を含む）。`grep -n "shL: \[-0\.115" stage-sketch.js` で全部出る。
- **次の7行は対象外。触らないこと**（特殊な姿勢で肩の位置が別に設計されている）:
  941, 1135, 1246, 1258, 1310, 1348, 1397 行目付近の `shL:`。
  判別法は単純で、**`shL: [-0.115` で始まらない行は対象外**。
- `BASE_JOINTS`（912行あたり）のコメントは変更不要。
