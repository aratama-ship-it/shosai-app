# 照明パネルから照明デザインモードへの移行候補

2026-09-13。旧パネルで作った照明を照明デザインモードへ移す純粋な変換モジュールと、編集・保存・復旧まで試せるローカル確認版。
製品本体や公開試作は変更していない。旧照明パネルの撤去・ベータ公開は未実施。

## 開く

このディレクトリで `python3 -m http.server 8944 --bind 127.0.0.1` を実行し、
<http://127.0.0.1:8944/demo/> を開く。「移行の見本を試す」で架空ショーを試せる。

実際に使うときは、舞台スケッチのショーを JSON に書き出し、「ショーのJSONを選ぶ」→移行内容を確認→「コピーを照明モードで開く」。
「保存」から専用のブラウザ保存・ファイル書き出しができる。「移行内容・元データ」から移行前のショーを取り出せる。
ファイルの読み込みで作業中のデザインを切り替えた場合、元に戻す操作で前のデザインへ戻れる。

## 対応と保持の扱い

| 旧データ | 移行先 |
| --- | --- |
| 登録済み照明とシーンの setId | 灯体と場面の対応記録。名前では結び付けない |
| シーンにある照明 | その場面で点灯。色・光源位置・狙い点を保持 |
| scene.stashed にある消灯中の照明 | 消灯のまま当て先・強さを保持。点灯操作で初期化しない |
| 登録プリセット | 消灯時の控えがない場合に使用。由来を記録 |
| 同じ登録で場面ごとに違う光源位置 | 配置を分け、各場面で該当配置だけ点灯する |
| 同名の未登録照明 | 場面・駒ごとに独立した灯体。推測で統合しない |
| どの場面にも位置のない照明登録 | 位置未設定で保持。光源位置3欄を設定するまで点灯しない |
| 旧 glow（0.1〜1.5） | glow / 1.5 × 100。旧値も保存 |
| 旧直径 | 光源から狙い点までの距離で円錐角へ換算。4〜70度を超えた場合は報告し近似。元の直径も保存 |
| セクション・人物・大道具・音楽参照・照明意図・未知フィールド | 復元用の元ショー全体に保持。新しい画面では照明と舞台寸法を表示 |
| 旧 lightMotion・場面転換の blackout | 元ショーに保持し、未変換項目として表示。消灯や別の動きへ読み替えない |

光だまり・明るさ・当たる面の描画モデルは異なるため、見た目の同一性は保証していない。
旧パネルとの実データ比較が終わるまで、旧パネルの撤去やベータへの統合には進めない。
照明の種類は静止の固定灯として扱い、旧 lightKind とメモ・錠は控えを保持する。新画面の編集ロックや機種の意味へは自動変換しない。
音源の実ファイルは元ショーJSONに元々含まれないため、元の端末の音源・別の控えが必要。

## モジュールの入口

`light-panel-migration.js` はブラウザでは `window.STAGE_LIGHT_PANEL_MIGRATION`、Nodeでは CommonJS。

```js
const M = require('./light-panel-migration.js');
const design = M.migrate(showDocument, {
  sourceText: originalJSONText,
  // 必要なときだけ確定した舞台寸法を指定する。
  stage: { W: 12, D: 9, H: 8 }
});
const report = design.migration.report;
const originalDocument = M.restoreOriginal(design);
const originalJSONTextAgain = M.originalText(design);
```

入力は舞台スケッチの project を持つ版3・4。古い平面版やZIPは、現在の舞台スケッチで開き、JSONへ書き出す。
未知の版、壊れた値・ID、重複参照は空のショーに置き換えずエラーにする。モジュールはI/O・保存・原本の変更を行わない。
再入力された移行済みデザインは検証してコピーを返し、灯を増殖させない。

移行ファイルは `shosai.light-design` version **2**。旧任意座標を持つ `mount.type: legacy-panel`、
範囲外の狙い点を保持する `coordinateMode: legacy-panel`、復元用の `migration` を追加するため、
version 1 の読込側に黙って渡してはいけない。
新モード本体に組み込むときは、この読み取り・座標処理・保存時の migration 保持を一緒に対応させる。
公開試作への上書き用パッチではなく、固定した試作を使った統合見本なので、現行の試作に丸ごと上書きしない。

`migration.originalDocument` は入力全体のコピー。`originalText` がある場合、原文を優先して復元する。
移行ファイルには復元用の元ショー全体（メモ等を含む）も入る。照明だけの共有ファイルではない。
新モードで行った編集は、この移行前の控えには逆反映しない。
新画面の専用保存キーは `shosai.lightDesignMigration.preview.v1`。
