## 最初に知っておくこと（ここを取り違えると全部無駄になる）

**二つのURLはまったく別物として振る舞う。**

| | URL | 中身 | Service Worker |
|---|---|---|---|
| **書斎**（身内用） | `https://shosai-app.juggler-arata.workers.dev/` | 資料棚・名簿・制作机＋舞台スケッチ | **無い** |
| **舞台スケッチ**（配る製品） | `…/stage.html` | 舞台スケッチだけ | **有る** |

- **オフラインとホーム画面PWAは `/stage.html` でしか成立しない。**
  書斎側（`/`）はSWを一切登録しないので、機内モードでは開かない。**これは仕様であり、不具合ではない。**
- タブレット専用UI・スマホ閲覧機モードも `/stage.html` でしか起動しない。
- どちらもBasic認証の内側にある。

---

## ★最重要: PWAのインストールがBasic認証を通れるか

**なぜ最重要か**: `stage-sw.js` の `cache.addAll()` は、APP_SHELL 22件のうち
**1件でも401が返ると全体が失敗し、Service Workerのインストールごと落ちる。**
落ちればオフラインは一切機能しない。認証の内側でPWAを配る構成なので、実機でしか確認できない。

### 手順（iPhone・iPadの両方で）

1. Safariで `…/stage.html` を開き、Basic認証を通す。
2. 共有 → **ホーム画面に追加**。
3. **Safariを完全に終了**（アプリスイッチャーから上へスワイプ）。
4. ホーム画面のアイコンから起動する。

### 見るところ

| 確認 | 期待 | 記録 |
|---|---|---|
| PWA起動時に認証を再度聞かれるか | 聞かれずに開く。聞かれても入力して開けばよい | |
| 開いた画面が正しく表示されるか | 舞台スケッチが出る。白画面・崩れが無い | |
| **機内モードにして再起動** | **開く**（＝SWのインストールが成功していた証拠） | |
| 機内モードで開かない場合 | ★**リリース阻止級。すぐ報告してほしい** | |

**どの端末で・どの向きで・何をしたら・どうなったか**が分かると、そのまま発注書へ載せられる。
