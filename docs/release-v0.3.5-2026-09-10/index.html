小道具と表示

  • ドラムセットと大太鼓を追加し、輪郭と立体感を滑らかに調整。
  • マスク（仮面）を追加。左右の手に持たせるほか、演者の顔へ装着できる。
  • 小道具の既存の色入力から、各小道具の色を変更できる。
  • 赤みの黒と、暗く淡い青みの黒を設定から切替。青みの黒では正面図・平面図の舞台面も連動。

操作まわり

  • 全画面表示、正面図・平面図の入替と補助表示。
  • 左右パネル幅の調整、シーン説明、シーン操作の整理。
  • 画像書き出しと印刷・PDFの選択画面を整理。
  • 横・縦・斜め2種・円・V字・逆V字の7種類で演者を整列。

PWA更新処理の位置づけ

この修正は、ベータ版や将来のWeb製品版をインストールして使う端末で、新しいファイルへ確実に切り替えるための処理です。共有セッションを演者へ送る機能とは別です。登録不要の体験版はPWAを配信していないため、この更新処理の直接の対象ではありません。

製品版を公開する前に決める一点

現在の正式提供仕様は、Googleまたはメール認証、7日試用、Normal・Company Pass・Enterpriseの契約、作品数・編集席の上限、団体と作品オーナーの権限を含みます。これらを実装して専用URLで出す案と、現在の認証付きフル版を無料の正式版として先に出す案は、公開物の意味が異なります。

推奨: v0.3.5のベータ版と体験版を今回の公開版とし、製品版は既存仕様どおりに認証・契約・製品URLを決めてから別環境へ公開します。
