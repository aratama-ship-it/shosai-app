### 1. 共有再生は(i)を推奨

**ホストが再生位置を決め、ゲストは無音で配置を追従**します。一人での確認と複数端末の稽古を同じ再生処理で扱え、音源の配布・端末ごとの再生開始調整を初版から抱えずに済みます。

最小契約は次です。

- ホストが`sceneId / motionRevision / seq / count / playing`を再生中は一定間隔、停止・シーク時は即送信。カウントは小数を許容。
- ゲストは同じ改訂版の配置データから描画。古い連番を破棄し、改訂不一致なら再取得まで停止する。
- 再生・停止・シークの要求はホストのみ受理。ボタンを隠すだけでなく、共有側でも送信者の権限を検証する。ゲストの視点変更は自由。
- 途中参加時は最新の配置データと再生状態を取得。通信断・更新途絶では最後の位置で止め、「同期停止」を表示する。

**これは通信遅延を伴う位置追従です。** ゲストの描画は短く補間できますが、全端末の厳密な同時表示は保証しません。実際の稽古で許容できる遅れかを試作で確認します。

ゲストは音源不要で、持っていても共有再生では無音。ホストに音源がない場合は音楽同期再生を開始できず、手動のカウント指定は可能とします。(ii)は端末側でも音を出す必要が確認されてから。(iii)だけでは今回の「両方」を満たしません。

### 2. 代表カウントは再生位置と分離

`motion.heroCount`を追加し、未指定は1。動きの範囲内で、補間途中の位置も選べます。

- **サムネイル**：常に代表カウントを描画。
- **単独で開くとき**：代表位置で停止。「先頭から再生」は1から始める。
- **香盤表**：出演・配置の正本は従来どおり場面データ。代表位置から出演者を推定しない。挿絵に使う場合だけ代表配置を描画。
- **演者ビューア**：単独閲覧は代表位置、共有追従中はホストの現在位置。途中参加でも代表位置へ戻さない。

代表位置を変更しても、共有中の再生位置は動かしません。

### 3. 場面内では床上移動だけ

初版のキーフレームは`u,v`のみ。対象演者は**場面を通して床上・乗降なし**とし、高さは既存の床基準から決めます。派生値の`base`をキーフレームへ保存しません。

移動中に台と重なっても、自動で登らせません。台上・支持物付きの演者は場面内移動の対象外と明示します。既存の「降りる→歩く→登る」は場面間転換に残し、場面内再生には適用しません。

### 4. ⑦⑨の試作範囲

**一場面・一曲・少人数の床上直線移動、配置点編集とUndo、代表カウント、ホスト音源による再生・停止・シーク、無音ゲストの配置追従・途中参加・通信断からの復帰までを一組で試作します。**
