# パネルの横幅調整 — 2026-09-10

本人指定: パネルの横幅をある程度自由に変えたい。

- PCの左右列の内側の境界をドラッグして別々に調整。240〜480px、既定268px、中央420pxを確保。1119px以下の既存縦積み表示では取っ手を隠す。
- タブレットの引き出しは240〜480px、図に280pxを残す。全画面の引き出しは280〜520px（タブレット最小338px）、画面端に88pxを残す。
- 幅は端末の環境設定 `panelWidths` へ保存。ショー、共有JSON、Undoに含めない。全画面と通常列は別設定。
- 左右キー10px・Shift併用30px、Home/Endで最小/最大、ダブルクリック・Enterで既定幅、Esc・pointercancelでキャンセル。role=separator、ariaの方向・名前・数値・説明を4言語で設定。
