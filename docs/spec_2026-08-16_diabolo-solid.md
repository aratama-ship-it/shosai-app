# 仕様書: ディアボロを「お椀2つを合わせた立体」として描く（2026-08-16）

対象: `stage-sketch.js`（描画のみ。データ・UI・寸法・置き方の仕組みは既存のまま）

## いまの状態と、なぜ直すか

`pieceParts()` の `diabolo` 分岐が、カップの縁の輪2枚と軸の線1本を返すだけになっている。
そのため**針金の輪が2つ浮いているように見え、ディアボロだと分からない**。

本人の要望は「**お椀を2つひっつけたようなリアルさ**」。
中身の詰まった立体として、くびれから縁へ広がる曲面が見えるようにする。

## 方針

輪や箱の組み合わせでは表せないので、**球（`drawSphere`）と同じく専用の描画関数**を持たせる。
やり方は「軸に沿って断面の円を並べ、その輪郭を塗る（ろくろ挽き）」。
断面は既存の `riggingPoint(piece, lx, ly, lz, L)` で画面へ落とすので、
**遠近・向き（facing）・床の1m枡との一致は既存の仕組みのまま効く**。

## 断面の形（プロファイル）

軸方向の位置を `t`（-1〜+1、0がくびれの中心）とし、その位置での半径を `r(t)` とする。

```
const R = d.dia / 2;          // カップの縁の半径
const AX = Math.max(0.006, R * 0.13);   // 軸の半径
const WAIST = 0.14;           // 軸だけの区間（|t| がこれ以下）
function radiusAt(t) {
  const a = Math.abs(t);
  if (a <= WAIST) return AX;
  const k = (a - WAIST) / (1 - WAIST);        // 0〜1
  // 指数を1未満にすると、くびれから一気に立ち上がって縁で寝る＝お椀の曲面になる
  return AX + (R - AX) * Math.pow(k, 0.62);
}
```

- サンプル数は片側16点（合計33点）程度。
- **縁（|t|=1）では必ず R** になること。

## 描き方

`drawDiabolo(target, piece, L)` を新しく作り、`drawSolid` の冒頭で
`piece.type === "diabolo"` のとき**そちらへ丸投げして return** する
（`pieceParts` の `diabolo` 分岐は削除してよい。他の種類には触れない）。

### 共通

- 色は `piece.color`。塗りは `rgba(piece.color, ...)`、輪郭は既存の道具と同じ
  暗い線（`rgba(0,0,0,0.35)` 程度、`lineWidth 1`）。
- **床の影**は既存の `drawSolid` が `pieceFootprint` から描いているものと同じ扱いにする
  （`drawDiabolo` の中で同じ楕円/矩形の影を描くか、`drawSolid` の影の処理を通してから
  分岐するかはどちらでもよい。影が無くなると床から浮いて見えるので**必ず残すこと**）。

### 横置き（`diaboloMode !== "stand"`。軸は左右＝x方向、軸の高さは床から R）

各サンプル `t` について、軸上の点は `lx = t * len / 2`（`len = d.w`）、高さ `ly = R`。
断面の円は**軸に垂直な面（yz面）**にある。輪郭は上端と下端:

- 上端: `riggingPoint(piece, lx, R + radiusAt(t), 0, L)`
- 下端: `riggingPoint(piece, lx, R - radiusAt(t), 0, L)`

1. **本体の塗り**: 上端を左から右へ、下端を右から左へ繋いだ閉じた形を塗る（砂時計の形）。
   塗りは `rgba(piece.color, 0.82)`、その上から輪郭線。
2. **陰**: 下半分を一段暗く。上端の代わりに「軸の高さ（`ly = R`）の線」を使い、
   軸の線と下端で閉じた形を `rgba(0,0,0,0.16)` で重ねる。これで筒の丸みが出る。
3. **縁の口**: 両端（`t = ±1`）に、半径 R の**楕円（yz面の輪）**を描く。
   奥側の縁は `rgba(piece.color, 0.5)`、手前側は `rgba(piece.color, 0.95)` で
   線を引く（お椀の口が開いていることを示す）。
   輪の点は `riggingPoint(piece, ±len/2, R + Math.sin(a) * R, Math.cos(a) * R, L)`。
4. **くびれの軸**: `t` が `±WAIST` の間を、太さ `AX * 2` の線で描く（`rgba(piece.color, 1)`）。

### 縦置き（`diaboloMode === "stand"`。軸は垂直、下のカップの縁が床）

各サンプル `t` について、軸上の高さは `ly = (t + 1) / 2 * len`。
断面の円は**床と平行（xz面）**。輪郭は左端と右端:

- 左端: `riggingPoint(piece, -radiusAt(t), ly, 0, L)`
- 右端: `riggingPoint(piece, +radiusAt(t), ly, 0, L)`

1. **本体の塗り**: 左端を下から上へ、右端を上から下へ繋いだ閉じた形を塗る。
2. **陰**: 左半分（左端と中心軸の線で閉じた形）を `rgba(0,0,0,0.16)` で重ねる。
3. **縁の口**: 上端（`ly = len`）に半径 R の**床と平行な楕円**を描き、
   `rgba(piece.color, 0.95)` の線で縁取ったうえで、内側を `rgba(0,0,0,0.22)` で塗る
   （上を向いたお椀の中が見える）。
   下端（`ly = 0`）にも同じ楕円を線だけで描く（接地の縁）。
   楕円の点は `riggingPoint(piece, Math.cos(a) * R, ly, Math.sin(a) * R, L)`。

## 完了条件

1. `node --check stage-sketch.js` が通り、`node --test tests/*.test.mjs` が全件通る。
2. 舞台へディアボロを置くと、**中身の詰まった砂時計形**（くびれから両側へ広がり、
   両端に口の楕円がある）に見える。針金の輪には見えない。
3. 縦置きにすると、立った軸のまわりに同じ曲面が見え、上を向いたお椀の中が見える。
4. 向き（facing）を変えると、縁の楕円の見え方が一緒に回る。
5. 床の影が残っていて、床から浮いて見えない。
6. 寸法（カップの直径・軸を含む長さ）を変えると形が追従する。
7. 実装後、変更点の要約を本ファイル末尾に「## 実装メモ(Codex)」として追記する。

## 実装メモ(Codex)

- `pieceParts()` のディアボロ用リング・軸線の組み合わせを、専用の `drawDiabolo()` に置き換えた。
- 横置きは33断面から砂時計形の本体を塗り、下半分の陰、両端の口の遠近2段階の縁、中央の軸を重ねた。
- 縦置きも同じ断面プロファイルで本体と左側の陰を描き、上の口には暗い内側、上下の縁、中央の軸を加えた。
- 投影はすべて既存の `riggingPoint()` を通し、寸法・向き・遠近へ追従させた。床の影は既存の `drawSolid()` の処理を通してから専用描画へ分岐するため維持される。
