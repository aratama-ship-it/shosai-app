選択灯「型」を、あとから直せる
実値として保存するための契約

32型の画面案を、試作で実装できる粒度へ下ろしたものです。ランダムは seed を持つ疑似ランダム、範囲は決定的な配り方、適用は一回のUndoです。

P0純関数・検証済み舞台スケッチ本体は未変更保存形式の変更を承認しない2026-09-14

今回、決めたこと

型は選択中の灯へ値を書き込む一括操作です。 適用後は既存の調整でそのまま直せ、型の定義を後から変えても過去のキューは動きません。型を“生きたレイヤー”として積み重ねる設計にはしません。

既存機能と混ぜない

触らないもの

`scene.lightMotion` は灯体・DMX・パン/チルトを持たない、シーン単位の「光の動き（案）」です。本体の照明プリセットも新しいライト駒を作る機能です。どちらにも今回の選択灯型を書き込みません。

最初に作るもの

試作 cue に対する純関数の属性パッチです。選択済みフィクスチャだけを対応判定し、狙い・動き・配り方など、カードが担当する属性だけを更新します。

型ごとの「変えるもの／保つもの」

家族変えるもの保つもの対応条件
狙い静止狙い点色・強さ・ビーム・ゴボ・点滅狙いを変えられる灯
範囲狙い点・ビーム幅・任意の強さ色・ゴボ・点滅狙いを変えられる灯
動き経路・周期・位相・関係色・強さ・ビーム・ゴボ・点滅ムービング灯
配り方色または強さ狙い・動き・ビーム・ゴボ該当属性を持つ灯
演出／点滅カードに明記した属性だけ担当外の全属性カードごとの対応条件

範囲型の「強さもそろえる」は既定ON。OFFなら強さを書きません。混在選択は、たとえば「ムービング6灯に適用・固定2灯はそのまま」と適用前に見せます。

ランダムに見える動きは、固定seedで作る

保存する

seed、経路版、許可領域、周期、ゆらぎ、位相、灯の順番。同じキューを開けば、同じ見た目を再現します。

再生時にする

seed と灯の順番から滑らかな閉じた経路を純関数で導きます。毎フレーム乱数を振らず、細かな震えや再生ごとの変化を避けます。

「別のばらつき」

新しい seed を明示して確定します。これは一回のUndoで戻り、再生・リロードでは勝手に変わりません。

{ kind: "wander", seed: 2841, pathVersion: 1,
  regionIds: ["stage"], loopSec: 10,
  irregularity: 0.55, phaseNorm: 0.33, fixtureRank: 2 }

客席を含む型: 舞台と、舞台図で明示した客席マスクの内側だけを通します。これは図上の動きの提案であり、設備・演者・観客への照射や現場安全を判定する機能ではありません。

範囲を複数灯で明るくする

既定の5範囲

舞台全体、下手半分、上手半分、前半分、奥半分は名前だけで再現できます。

指定範囲 v1

舞台図をドラッグして作る正規化矩形に限定します。端点をそろえ、範囲外・極小範囲を検査します。

配り方

灯と狙い点を物理的な下手→上手順で安定して結びます。「選んだ順」を明示した時だけ選択順を使います。

ポリゴン指定と最短マッチングは将来候補です。v1 は再現性と説明可能性を優先し、均等格子と安定ソートにします。照度計算・均一照明の保証ではありません。

適用は一回のトランザクション

1. 事前判定対応灯、除外理由、領域を確認
2. パッチ生成元cueを変えず、担当属性だけ計算
3. 正規化無効値を除き、no-opなら中止
4. 一回だけ記録checkpoint → 書き込み → 保存
5. 通知再描画し、対象とUndoを伝える

スライダーや範囲ハンドルの途中操作はドラフト表示だけ。確定時に一度だけ履歴へ積みます。未知キー、担当外属性、非対象灯は保持します。

本体へつなぐ前の合格ライン

  • 同じseed・灯順・時刻なら同じ位置
  • seed変更時だけ経路パラメータが変わる
  • 全サンプル点が許可領域に収まる
  • 入力配列の順に結果が左右されない
  • 範囲6種が正規化される
  • 混在選択は非対応灯を変えず理由を返す
  • 担当外属性と未知キーが保存される
  • 適用と再抽選が各一回のUndoで戻る
  • no-opで履歴・保存・通知を増やさない
  • 旧cueと未知の経路版を壊さない

P0 / P1の現在地

実装・確認済み

32型の宣言、選択灯への不変パッチ、固定seedのwander、客席マスク必須判定、範囲6種、属性保全、no-op判定を隔離した純関数として実装しました。既存の照明デザイン試作では、2灯以上の選択時だけ入口を出し、検索・カテゴリ付きの32型モーダルからcueへ一括適用します。6灯への適用と一手Undoをブラウザで確認済みです。

接続しない範囲

舞台スケッチ本体、保存済みプロジェクト、ベータ、公開物には接続していません。客席まで漂う型は、会場ごとの客席マスクが未接続のため試作でも無効にしています。
