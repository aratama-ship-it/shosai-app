**確定版は「常設の吊位置を使った仮想仕込み＋照明のあるある30件を重ねる入口」とします。** ストーリーや完成ルックの組合せは作りません。

Fableの解釈は概ね採用します。ただし、次の3点を修正します。

- 常設を模すのは主に**吊位置と構成**。全ムービング、SS、転がしまで常設設備だとは表示しません。
- 競合は「配置グループ」だけでなく、**実際の灯体ID×変更属性**で判定します。

Matt KizerのLight Labからは、方向・色・強さ・模様を個別に試す考え方を採ります。公式説明にも、方向別のゴボ操作や、トップ・サイド等の色と強さの操作が示されています。[Light Labs](https://scenicandlighting.com/lightlabs/)

| サイズ | 面用の狙い `(u,v)` |
|---|---|

|---|---|---|

**B. 合成規則の確定**

**1．プリセットの適用範囲**

通常カードは `mode:"patch"`。ただし操作を2種類に分けます。

| 操作 | 書き換えるもの |
|---|---|
| `operation:"setup"` | 指定した灯体集合の明かりを、そのあるあるの状態へ作り直す |
| `operation:"attributes"` | 色、強さ、位置の動きなど、列挙した属性だけ変更 |
| `mode:"reset"` | 「全部消す」専用。現在cueの全灯を消灯 |

例えば「前明かり中央」はCL全体を対象にし、面用を消して中央用2灯を点けます。**SS・FR・ホリ等は残ります。** 「舞台上で中央以外を全部暗くする」操作ではありません。

**2．setupの初期化契約**

対象灯だけ、既知の照明属性を中立状態へ戻してから設定します。

- 点灯・強さ・色・狙い・広がり・ゴボ・点滅・カッター・時間設定を対象にする。
- 未使用の対象灯はoff。対象外の灯には触れない。
- 固定灯の狙いは仕込みの共通狙いへ戻す。
- 固定角度、バーンドア、cycの長さ・到達高さ、舞台寸法は変更しない。
- 対象灯を既存の動きの組から外す際も、対象外灯の軌道・位相を変えない。
- 未知フィールドは保持する。

したがって「地明かり→ゴボ木漏れ日」が同じWASHを使う場合、地明かりの設定は置換されます。両方が別の光として加算されるわけではありません。

**3．同一灯体の競合**

**灯体ID×属性で後勝ち**です。1灯から違う方向の光を同時に出す合成はしません。

- ホリの色変更：`color` のみなら強さや他グループは維持。
- ゴボを含むsetup：対象集合の以前の動きや模様も置換。
- 地明かり＋位置の往復：地明かりの色・強さを保ち、軌道を変更。

カード内の色選択や既存の色調整は属性変更です。カード本体の再適用とは区別します。

**4．動きを既存の明かりへ当てる**

初版の動きは**床を狙う、点灯中のムービング**が対象です。

- 灯体選択あり：選択内の適格灯。
- 選択なし：現在cue内の適格灯。
- 色・強さ・広がり・ゴボは維持。位置の軌道と同期設定を置換。
- 対象0灯なら無変更。灯を勝手に追加・点灯しない。
- 往復・円は1灯以上、扇・順送りは2灯以上。
- 固定灯、空中・客席向けの灯は対象外。

現行モデルは位置・強さ・ズームの自動変化で時間基準を共有します。初版では `levelTo` または `beamDegTo` による自動変化がある灯も対象外とし、適用件数を表示します。「位置だけ変えたつもりで強さの動きも変わる」を避けるためです。

**5．点いていないグループへの色変更**

- **見本カード**を押す：必要な狙い・強さを含めて点灯する。
- **色だけの操作**：消灯を維持し、色を保存する。「色を設定・消灯中」と表示する。

色だけの操作に、暗黙の点灯や既定値の再投入を混ぜません。

**6．「全部消す」**

全灯の `on=false` のみ。色・強さ・狙い・動きの設定は保持します。再生は停止し、Undoで消灯前へ戻せます。既存キューやrigの削除、全属性の初期化はしません。

**JSONの変更**

```json
{
  "mode": "patch",
  "operation": "setup",
  "scope": { "groups": ["CY.lower", "CY.upper"] },
  "reset": {
    "scope": "targetFixtures",
    "profile": "light-neutral-v1",
    "groups": "detach-targets-preserving-others"
  }
}
```

色だけの変更：

```json
{
  "mode": "patch",
  "operation": "attributes",
  "scope": { "groups": ["CY.lower", "CY.upper"] },
  "writes": ["color"],
  "reset": null,
  "activate": false
}
```

全部消す：

```json
{
  "mode": "reset",
  "reset": {
    "scope": "cue",
    "operation": "blackout",
    "preserveSettings": true
  }
}
```

`requires`、解決した灯体割当、属性ごとの由来記録は継続します。対応はこの3仕込みのみ。1クリック＝1commit、同じ結果への再適用は履歴を増やしません。

| クリック | 対象灯を選択し、既存の調整タブを開く |
| 再クリック | 消灯・解除・再適用はしない |
| ×ボタン | 付けない。取り外せるレイヤーに見せない |

同じ枠が全面的に置換されたら古いチップを外します。例えばホリ青→ホリ赤で、青と赤の2個は残しません。

一部の属性が残る場合は「調整あり」を添えます。地明かりへ往復を加えた場合は、同じ灯の説明としてまとめます。全灯消灯時は「点灯中の明かりなし」と表示し、保存されている設定を消した扱いにはしません。

**カードの状態**

| 状態 | 表示 | 押したとき |
|---|---|---|
| 乗っていない | 通常枠、「適用」 | 対象範囲へ適用 |
| 適用中 | brass枠＋チェック＋「適用中」 | 結果が同一なら無変更 |
| 由来は残るが変更済み | 「適用中・調整あり」 | そのカードの対象設定へ戻す |
| 同じ枠を使う別案 | 「ホリを置換」等の短い札 | 即置換、Undo可 |
| 対応条件を満たさない | 適用不可と具体的理由 | データを変更しない |

「競合」をエラー色で警告し続けません。**何が置き換わるかを操作前に読める状態**にします。新たな確認ダイアログは挟みません。

サムネイルも合成規則に合わせ、**現在cueへそのカードを適用した結果**を描きます。主画面と異なる作業灯設定を強制する前回案は撤回し、現在の描画設定を継承します。操作ハンドル・番号等の編集用表示だけを省きます。

これにより、前明かりが点いた状態でホリのカードを見ると、前明かりを残した結果がサムネイルにも出ます。元cue・適用対象・描画設定をキャッシュキーへ含め、表示中カードから更新します。古い条件の画像を、更新済みとして表示しません。

**確定**

- 常設の吊位置をイメージした仮想仕込み。照明バトンは小2本・中大3本、全ムービング。
- 灯体配列は小34・中54・大70要素。SSムービングを削除し、転がしを小2・中大4灯へ縮小。
- ストーリーを組まず、照明のあるある30件を用意する。色違いの一部は色選択へまとめる。
- patchが既定。setupと属性変更を区別し、灯体ID×属性で後勝ち。
- 「全部消す」は消灯のみで設定保持。カード適用は即commit・Undo可。
- 固定灯の共通狙いとrigをプリセット適用で変更しない。
- チップは現在の由来と調整先を示す。取り外せる層にはしない。
- サムネイルは現在cueへの適用結果を、現在の描画設定で示す。
- 既存rigの差替え、本体統合、公開は今回の作業に含めない。
