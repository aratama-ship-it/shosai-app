# 1. 画面構成の批評と確定案

## 判断

**3列構成を採用します。正面図はタブへ隠さず、平面図の下に細長く常時表示します。**

このアプリでは、灯体をクリックしにくい場面、消灯中の灯体、組の所属、未設定灯の確認があります。中央図と設定欄だけでは、灯体数が増えたときに全体を監査できません。左の一覧は必要です。

一方、Claude案の上帯は詰め込みすぎです。タイトル、モード、シーン送り、適用、破棄を横一列に並べると、最も重要なモード名と現在のシーンが埋もれます。

## 1440×900での確定寸法

モーダル外寸を **1180×840px** とします。

```text
┌──────────────────────────────────────────────────────────┐
│ タイトル    配置｜動き        未適用    適用して閉じる × │ 60px
├──────────┬───────────────────────────┬───────────────┤
│ 灯体一覧 │ シーン名・再生操作       │ 選択中の設定  │
│ 196px    ├───────────────────────────┤ 292px         │
│          │ 平面図 636×410px         │               │
│          ├───────────────────────────┤               │
│          │ 正面図 636×150px         │               │
│          ├───────────────────────────┤               │
│          │ 操作案内・座標凡例 36px  │               │
└──────────┴───────────────────────────┴───────────────┘
```

本文の左右余白を16px、列間を12pxとすると、

```css
grid-template-columns: 196px minmax(0, 636px) 292px;
gap: 12px;
```

が目安です。中央列だけ可変にし、左196px、右292pxは固定します。

右292pxなら、短いラベル、2〜3択のボタン、数値と単位を一行に収められます。左196pxでは、各行に複製・削除を常時出す余裕はありません。行には番号・名前・設置場所・状態だけを表示し、複製・削除は一覧上部または右設定欄へ移します。

## 正面図を常時表示する理由

正面図を隠すと、トラス高さ、横置き灯の高さ、奥壁への照射が「詳細設定」に見えてしまいます。しかし今回の核は、灯体の実位置から光が出ることです。小さくても常に見える方が、位置と光線の関係を理解できます。

ただし、通常の座標編集は平面図を主にします。

- 平面図：横位置、奥行き、床上の照射先を編集
- 正面図：トラス高さ、横置き灯の高さ、奥壁の照射先を編集
- 奥壁を選んだとき：正面図を一時的に高さ240pxまで広げ、平面図を縮める

常時表示と必要時の拡大を併用する構成です。平面・正面を排他的なタブにはしません。

## 上帯の整理

上帯は次の二段階にします。

- 左：`照明を組む`
- 中央：`配置（ショー共通）｜動き（このシーン）`
- 右：`未適用の変更あり`、`適用して閉じる`、閉じるボタン

シーン送りは上帯に置かず、中央列のプレビュー直上へ置きます。

```text
〈 前のシーン　シーン 4「登場」　次のシーン 〉
```

これにより、「現在どの場面を見ているか」がプレビューと隣接します。

`変更を破棄`は上帯へ常設しません。誤操作の危険が高いため、未適用の状態で閉じたときだけ、モーダル内に次を出します。

```text
変更がまだ適用されていません。
［編集に戻る］［破棄して閉じる］［適用して閉じる］
```

# 2. 配置モードの操作仕様

## 基本状態

配置モードは次の五状態を持ちます。

```text
選択
  ├─ トラス配置中
  ├─ 灯体配置中
  ├─ ドラッグ調整中
  └─ 複数選択中
```

どの配置ツールも、`Esc`または同じボタンの再クリックで選択状態へ戻ります。現在の状態はキャンバス左上へ常時表示します。

## トラスを置く

1. `トラスを足す`を押す。
2. 平面図上に、ポインターの奥行きへ追従するトラスの半透明予告を出す。
3. 既存トラスへ近い場合は、重なりを避ける候補位置へ予告だけ吸着する。
4. クリックすると配置を確定し、そのトラスを選択する。
5. 右欄に名前、奥行き、高さを表示する。
6. 配置後は選択状態へ戻す。

新しいトラスの高さは、二本目以降なら直前に作ったトラスの高さを継承します。最初の一本だけは会場内に収まる仮の高さを入れ、`仮の高さ`と表示します。

トラスを上下方向へドラッグすると奥行きを変更します。灯体はトラスとの所属を維持したまま一緒に動きます。

## トラスへ灯体を置く

「トラスを選んだだけで、クリックするたび灯体が増える」仕様にはしません。選択と追加が衝突するためです。

1. トラスを選択する。
2. `灯体を足す`を押す。
3. ポインターがトラスへ近づくと、トラスを真鍮色で強調し、灯体の半透明予告を出す。
4. 予告の近くに `奥から2列目に置く` と表示する。
5. クリックすると、その位置へ灯体を追加する。
6. 追加後も灯体配置状態を維持し、続けて置ける。
7. `配置を終える`または`Esc`で終了する。

無効な場所では予告灯体を出さず、`トラスの上をクリックしてください`と表示します。

## 灯体を動かす

- クリック：その灯体を選択
- ドラッグ：同じトラス上を横移動
- ドラッグ中：現在位置と吸着先を半透明で表示
- マウスを放す：一回の変更として確定
- `Esc`：ドラッグ開始前へ戻す
- `元に戻す`：確定後でも一操作分を戻す

横移動中は、別トラスへ勝手に移しません。

## トラス間を移す

初回は右欄の `取り付けるトラス` で移動先を選びます。横位置は維持します。

```text
取り付けるトラス
［奥から2列目 ▼］
```

別トラスへ近づけただけで所属が変わる操作は採りません。これはLuminaPlotの最寄りスナップをそのまま採らない点です。図面作成ソフトでは便利でも、舞台の奥行きが短い画面では意図しない付け替えが起きやすいためです。

将来、修飾キーを押しながら別トラスへドラッグする操作は追加できます。

## 複製

1. 灯体を一灯以上選ぶ。
2. `複製`を押す。
3. 同じトラス上の少し右へ複製する。
4. 空きがなければ左へ置く。
5. 新しい灯体を選択状態にする。
6. 直後に `3灯を複製しました　元に戻す` を表示する。

`D`はキャンバスにフォーカスがあり、文字入力中でない場合だけショートカットとして使えます。画面上のボタンを主操作にします。

## 等間隔

同じトラス上の3灯以上を選択したときだけ、`等間隔に並べる`を有効にします。

- 左端と右端の灯体は固定
- その間の灯体だけを等間隔に配置
- 適用後にUndo可能
- 異なるトラスの灯体が混じる場合は無効
- 無効理由をボタン近くに表示

二灯では結果が変わらないため無効にします。

## 高さ

トラス灯は各灯体に高さを持たせず、**トラスの高さを継承**します。

トラスを選ぶと、正面図に高さハンドルを表示します。

- ハンドルを上下へドラッグ：トラス全体の高さを変更
- 右欄の高さ入力：細かな調整
- 灯体を選択した場合：`高さ 約5.0m（トラスから継承）`
- 灯体だけを上下へドラッグする操作：無効

床灯の高さは床置きの描画用既定値、横灯は個別の概略高さを持ちます。

## LuminaPlotから採る点

- 灯体一覧、中央図、インスペクタの分担
- 配置前の吸着予告
- 図をクリックして選択
- Shiftによる複数選択
- 複数灯への一括操作

採らない点は、パレットから毎回長距離をドラッグする操作、最寄りトラスへの自動的な所属変更、高さを数値欄だけで設定する方法です。

# 3. 動きモードの操作仕様

## 一灯を設定する流れ

### 1. 灯体を選ぶ

一覧、平面図、正面図のどこからでも選択できます。三つの表示は常に同じ選択状態を共有します。

未設定灯を選ぶと、右欄の最上部に次を出します。

```text
このシーンでは未設定です。
［点灯を設定］［消灯を設定］
```

### 2. 点灯と当てる面を決める

`点灯を設定`を押すと、

```text
当てる場所
［床］［奥の壁］
```

を表示します。床を選ぶと平面図、奥壁を選ぶと正面図が主編集面になります。

最初の照射先は舞台中央へ仮置きし、ハンドルと`仮の位置`を表示します。選択直後から光線を確認できる状態にします。

### 3. 一灯の動きを選ぶ

一灯選択時の型は三つだけです。

```text
動き
［止める］［往復］［円］
```

- `止める`：照射先ハンドルを一つ表示
- `往復`：A、Bの二点を表示
- `円`：中心、円周上の開始点、半径ハンドルを表示

型を切り替えた場合、可能なら直前の照射先を新しい軌道の中心として使います。元の軌道はUndoで戻せます。

### 4. A・Bと開始方向を調整する

往復では、AとBをドラッグして動く範囲を決めます。

右欄には、曖昧な`方向`を置かず、次を表示します。

```text
始め方
［A → B］［B → A］［中央 → A］［中央 → B］
```

キャンバスでは開始点を塗りつぶし、最初に進む方向を矢印で表示します。

円では次に変えます。

```text
始める位置　［円周上のマーカーを動かす］
回る向き　　［時計回り］［反時計回り］
```

時計回りの基準は、現在表示している床面または奥壁を正面から見た方向です。

### 5. 速さを決める

```text
1往復の時間
［ゆっくり 4秒］［普通 2秒］［速い 1秒］
```

円の場合は`1周の時間`へ変えます。秒数は最終仕様ではなく初期候補です。表示名だけにせず、渡される相手が解釈できる実時間を併記します。

### 6. 再生する

中央列の上に置きます。

```text
［最初へ］［再生］［停止］  0.0秒
```

- `Space`：再生／停止。ただし文字入力中は反応しない
- `最初へ`：全灯を0秒へ戻す
- 再生対象：現在シーンの設定済み灯体すべて
- ハンドルを触った時点：再生を停止し、編集へ移る

一灯を選択していても、他の灯を消しません。選択灯を強く、他灯を薄く表示します。必要なら後段で`選んだ灯だけ見る`を追加します。

## 組を作る流れ

### 「グループ」ではなく「組」

ASLSの考え方から採るのは、複数灯の時間関係を一つの単位として保持する点です。画面では次の言葉だけを使います。

- `選んだ灯体を組にする`
- `この組の灯体`
- `組の順番`
- `組から外す`

`位相`、`オフセット`、`ファニング`は通常画面に出しません。

### 状態遷移

1. Shiftクリックまたはチェック欄で二灯以上を選ぶ。
2. 右欄に`選んだ灯体で組の動きをつくる`を表示。
3. 次の五つから選ぶ。
4. 選択直後に全灯へ反映し、プレビューを更新。
5. `4灯を「順番に動く」にしました　元に戻す`を表示。
6. 左一覧に組の見出しを作り、その下へ灯体を並べる。
7. 組の見出しを選ぶと組全体、灯体行を選ぶと一灯の軌道を編集できる。

```text
組の動き
［一緒に動く］
［鏡のように動く］
［順番に動く］
［扇に開く・閉じる］
［交差して入れ替わる］
```

### 扇・交差の統合方法

扇と交差を、一灯の型には出しません。上の`組の動き`に一度だけ出します。

内部では次のように展開します。

- 扇：各灯へ往復軌道を作り、中心から外へ開く関係を設定
- 交差：選択した二灯の照射先が入れ替わる往復軌道を作る
- 順番：メンバー順に開始時刻をずらす
- 一緒：共通の時間進行を使う
- 鏡：基準軸に対して軌道を反転する

その後、一灯を選んでA・Bを動かせます。個別調整した組には`調整済み`と表示します。

`扇`と`鏡`、`交差`と`向かい合わせ`を別々の設定欄に置くと、どちらが優先されるか分からなくなります。五つを同じ選択面へ統合する方が理解しやすいです。

順番に動く組では、左一覧の並びが実際の順番になります。ドラッグで並べ替えられ、各行へ`1、2、3…`を表示します。

# 4. フィードバックと状態表示

## 選択

色だけに依存させません。

- 選択中：太い輪郭、灯体番号の反転表示
- 複数選択：各灯にチェック、右欄上部に`4灯を選択中`
- 組全体：灯体を細い括弧線で結び、組名を表示
- キーボードフォーカス：選択とは別の外枠

一覧・平面図・正面図で同じ番号を使います。

## 吸着予告

確定前は次の三つを同時に示します。

- 半透明の灯体
- 吸着先トラスの強調
- `奥から2列目に置く`という文字

吸着できない場合は、灯体の予告を消して理由を表示します。色が変わるだけの予告では不足です。

## 灯体の状態

一覧ではドットだけで済ませず、短い文字を併記します。

| 状態 | 一覧 | プレビュー |
|---|---|---|
| 未設定 | 白抜き丸＋`未設定` | 灯体のみ。光線なし |
| 消灯 | 斜線入り丸＋`消灯` | 暗い灯体。光線なし |
| 点灯・静止 | 塗り丸＋`点灯` | 光線と照射先 |
| 点灯・動きあり | 再生記号＋`動き` | 光線、軌道、照射先 |

照射色は別の色見本として表示し、状態記号へ流用しません。

## 再生中

プレビューのすぐ上に、

```text
再生中　2.3秒　［停止］
```

を高コントラストで出します。選択灯の番号と軌道も残します。

再生中にハンドルをつかむと停止し、`調整するため再生を止めました`と短く表示します。

## 書き出し中

右下の小さな状態文だけでは不足します。中央プレビュー上部へ固定帯を出します。

```text
動画を書き出しています　62%
この画面を開いたままにしてください。　［中止］
```

書き出し中は、シーン変更、適用、閉じる、配置変更を無効にします。停止操作だけは常に残します。

## 未適用

上帯に常時表示します。

```text
未適用の変更あり
```

適用後は数秒間だけ、

```text
ショーへ適用しました
```

へ切り替えます。

モーダル内のUndoは、最後に適用した状態まで戻せます。適用後は本体側のUndoでも一回の変更として戻せるようにするのが自然です。

## 会場エディタの作法で足りるか

**足りません。**

流用できるのは、暗い作業面、設定箱、モードボタン、キャンバス操作、保存境界、フォーカス復帰です。

照明画面には追加で次が必要です。

- 複数選択
- 一覧・二つの図・設定欄の選択同期
- 組の階層表示
- 再生状態
- 書き出し進行
- 未設定／消灯／点灯の区別
- モーダル内Undo
- 未適用状態と閉じる際の分岐

# 6. 触れる試作で必ず示す操作

本人の判断用試作では、次の8項目を一つの流れで触れるようにします。

1. 空状態から`奥トラス1本＋ムービング4灯`の予告を出して配置する。
2. トラス上へ灯体をクリック追加し、吸着予告を見る。
3. 灯体を横へ動かし、正面図でトラス高さを変更する。
4. 灯体を複製し、4灯以上を等間隔に並べる。
5. `動き（このシーン）`へ切り替え、一灯へ往復とA・Bを設定する。
6. 二灯を選び、`扇に開く・閉じる`または`交差して入れ替わる`を設定する。
7. 未設定・消灯・動きありの灯が混在する状態で全体を再生する。
8. 未適用表示から適用し、動画・図・灯ごとの説明を書き出す入口まで進む。

試作の評価点は、装飾の好みより次の五つです。

- どの灯を触っているか迷わないか
- 配置と動きを自然に往復できるか
- 一灯の修正と組全体の修正を区別できるか
- 平面図と正面図の対応が分かるか
- 未設定と消灯を取り違えないか

# 7. 逆張り：平面図＋右設定欄だけの最小案

この立場にも強みがあります。1180px幅なら、

```text
平面図 812px ｜ 設定欄 300px
```

とでき、照射先のA・Bや複数灯の軌道をかなり大きく扱えます。

灯体一覧は常設せず、平面図上の灯体を直接選びます。右欄上部に現在の灯体を切り替えるプルダウンを置きます。

```text
灯体：L03 中央ムービング ▼
```

未設定灯の確認だけ、`灯体 4／未設定 2`を押すと一時的な一覧ドロワーを開きます。正面図は`平面｜正面`の切り替えにします。

この案の長所は明確です。

- 平面図が約180px広い
- 初見で操作対象が一つに見える
- 4灯程度なら、図を直接触る方が速い
- 触れる試作を短期間で作りやすい

弱点も明確です。

- 灯体が重なると選べない
- 消灯中・未設定の灯を見落としやすい
- 10灯を超えると灯体の確認が遅い
- 組のメンバーと順番を表示しにくい
- キーボード操作や一覧監査に弱い
- 平面と正面を往復すると選択対象を見失いやすい

したがって、**4灯の操作感だけを見る初回プロトタイプとしては成立しますが、製品MVPには3列案を推します。** UI品質を判断する試作なら、二列案を作るより、3列案の左一覧を折り畳めるようにした方が比較しやすいです。

# 8. 本人に確認すべきUI上の未決事項

1. **通常、一つのショーで扱いたい灯体は何灯程度ですか。4〜8灯、10〜20灯、20灯以上のどれが近いですか。**  
   一覧の密度、組の階層、検索や絞り込みの必要性が変わります。

2. **正面図では、トラス高さや奥壁の照射先を直接ドラッグしたいですか。それとも、正面図は確認用で数値調整だけでもよいですか。**  
   常時150pxの補助図で足りるか、編集時に拡大する必要があるかが決まります。

3. **編集内容は「適用して閉じる」まで本体へ反映しない方式でよいですか。それとも、操作のたび本体へ反映し、本体のUndoで戻せる方がよいですか。**  
   dirty表示、閉じる操作、Undo、シーン送りの保存境界が大きく変わります。
