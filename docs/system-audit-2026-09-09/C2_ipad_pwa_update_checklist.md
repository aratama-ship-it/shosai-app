# C-2 iPad 実機: PWA更新の確認手順（WO-A2 実装後に本人が行う・2026-09-09）

コードを読むだけでは届かない不具合がある（2026-08-24〜25 の実例）。WO-A2 を入れて配った後、**必ずこの手順を1回通す**。
所要 15分。結果は下の表に記入して `docs/QA_PWA_UPDATE_<日付>.md` として残す。

## 準備

- iPad のホーム画面に追加済みの舞台スケッチ（`stagesketch.pygmix.com/stage`）。未追加なら Safari で開き「ホーム画面に追加」。
- テスト用のショーを1本作って保存（場面2つ・演者2人・付箋1枚）。**本物のショーは使わない**。
- 画面左上のバージョン表示を控える（旧版）。デプロイ後の新版の番号（`?v=` と `CACHE_NAME`）は実装セッションの報告から。

## 手順と合否

| # | 操作 | 期待 | 結果（○／×・メモ） |
|---|---|---|---|
| 1 | 旧版のまま、機内モード（Wi-Fi も切る）→ PWA を起動 | 起動でき、テスト用ショーが開く（旧版のオフラインが効いている） | |
| 2 | 機内モード解除 → PWA を開いたまま 10 秒待つ → 完全に閉じる（アプリスイッチャーから上へ） | （新SWが取得・install される想定） | |
| 3 | **すぐに**機内モードへ（新shellの補充が終わる前を狙う）→ PWA 起動 | **起動できる**（旧版または新版のどちらか。白画面・「ページを開けません」は×） | |
| 4 | 3 で開いた画面のバージョン表示 | 旧版なら「旧HTML＋旧JS」、新版なら「新HTML＋新JS」。**旧と新が混ざった表示・JSエラーは×** | |
| 5 | 機内モード解除 → PWA を開いたまま 30 秒待つ → 閉じる → 起動 | 新版の番号になる | |
| 6 | 5 の状態で機内モード → 起動 | 新版のままオフラインで起動できる | |
| 7 | テスト用ショーの内容 | 1〜6 を通して失われていない（場面2・演者2・付箋1） | |
| 8 | Safari（PWAでないタブ）で同じURL | 新版。Console に CSP 違反が出ない（WO-A5 を同時に入れた場合） | |
| 9 | 設定 → ストレージ（iPad: 設定 → Safari → 詳細 → Webサイトデータ）で `stagesketch.pygmix.com` の容量 | 旧キャッシュが片付いて極端に増えていない（目安 10MB 未満） | |

## 判定

- 3・4・6・7 がすべて○で合格。1つでも×なら実装セッションへ差し戻し（×の番号とバージョン表示の写真を添える）。
- 合格後、`WO_A2` の完了報告に「実機確認 合格（日付・iPadOS版）」を追記する。
