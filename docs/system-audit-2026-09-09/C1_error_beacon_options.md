# C-1 クライアント側の異常を知る手段（判断材料・2026-09-09・未実装）

## いま無いもの

- `stage-sketch.js`／`stage-pwa.js` に `window.onerror`／`unhandledrejection` のフックは0件。
- 利用計測（`usage-metrics.js`・未デプロイ）は「使われ方」（起動・手前操作の日数と時間）で、「壊れ方」は届かない。
- 利用者からの連絡は〈感想を送る〉の Google フォーム（`FEEDBACK_URL`）のみ。テスターが黙って離脱した場合に気づけない。
