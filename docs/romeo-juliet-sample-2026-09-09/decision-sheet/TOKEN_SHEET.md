# ロミオとジュリエット判断シート — 設計・トークン

## 設計メモ

- 使う人と目的: 本人が、通し稿と舞台スケッチの未確定部分を一度に選び、次の制作へ渡せる回答を作る。
- 使用感: 既に決めたことを再質問されず、上から答えるだけで残りが減る。中断しても同じHTMLから再開できる。
- 固有の核: 3大場面・10名・身体表現を軸にした今回のロミオとジュリエット。一般的なアンケート風の装飾ではなく、上演稿へ書き込む朱筆のような構造にする。
- 採用構造: 「確定済み」を折り畳み、判断だけを全体→美術・音→場面→反映の順で並べる。各設問は推奨、理由、別案の影響を同じ場所で比較。未回答フィルターと一括入力を置く。
- 外した案: 全項目をカードのダッシュボードにする案、1問ずつ送るウィザード、推奨を初期選択して本人回答に見せる案。今回は一覧性、比較、回答の出典を優先する。
- 機能条件: file://で単体動作、外部通信なし、localStorage自動保存、回答コピーとJSON保存、印刷、390px/1440px、キーボード操作、色だけに頼らない状態表示。
