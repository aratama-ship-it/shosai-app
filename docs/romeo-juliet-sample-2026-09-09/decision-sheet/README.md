# ロミオとジュリエット — 本人判断シート

`index.html` は、2026-09-11時点の通し上演稿と舞台スケッチ用サンプルから、本人の判断が必要な部分だけを取り出したローカルHTMLです。既に本人が指定・採用した構成は「決定済み」として再質問しません。

21件を全体方針、美術・音、場面詳細、反映範囲に分けています。各項目にはAIの推奨案と理由がありますが、初期状態では何も選択されません。「推奨案を一括で入れる」は本人が明示的に押した場合だけ回答へ反映します。「保留」も回答として保存されます。

回答はブラウザ内のlocalStorageへ自動保存します。「回答をコピー」でこの会話へ貼る文章を作り、「回答JSONを保存」で機械可読データを保存します。外部への送信機能はありません。ファイルを別名・別場所へコピーすると保存領域が変わる場合があるため、移動前にJSONを保存してください。

回答JSONは `romeo-juliet.user-decisions.v1`。`RJ-DEC-01`〜`RJ-DEC-21` の選択、自由記入、制作条件、参照元を保持します。回答を受け取った次のセッションは、`RJ-DEC-21` の反映範囲に従い、既存の本人指定を上書きせず、変更前後の対応を残してください。
