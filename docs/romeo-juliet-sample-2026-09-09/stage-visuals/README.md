# 舞台構成図

人間向けの入口は `index.html`。3場面・19内部キューに対応する28の瞬間を斜め図／平面図で表示する。PNG保存は選択中のSVGをブラウザで描画して保存し、SVG保存は元の図を保存する。

## 正本と生成

- `layouts.json`: 各図の相対座標、出演者、役としての登場／匿名の群衆、向き、姿勢、移動案、照明の意図、根拠と未決定事項。
- `build_visuals.py`: `layouts.json` から `svg/*-iso.svg`, `svg/*-plan.svg`, `index.html` を生成。
- `template.html`: 構成図帳のUI。データはビルド時に埋め込み、外部ライブラリは使用しない。
- `../condensed-show/build_outline.py` と `../condensed-show/scene-02/build_script.py`: この図の一覧を読み、各場面／各キューへ画像とリンクを挿入する。

このフォルダを cwd にして、次で再生成する。

```sh
python3 build_visuals.py
python3 ../condensed-show/build_outline.py
python3 ../condensed-show/scene-02/build_script.py
```

既存の日本語下訳と台本JSONは今回変更していない。演出変更があったら、まず該当する台本・ノートを確認し、この図の同じ cueId に対応する全フレームを更新する。sourceHashes は作図時の資料を記録し、最新の台本と同一であることを自動更新で装わない。

## 作図上の前提

u=0が客席左、u=1が右。v=0が奥、v=1が手前。実寸は未設定。冒頭は既存ブロッキング案の相対座標を使用し、他の配置は演出指示から作成した検討案。

同一図に同じ出演者を二度置かない。群衆の番号はその図だけの識別子で、配役IDと混同しない。死んだ役の担当者が人の川や終幕に現れる場合は匿名の群衆として記録する。大道具さんは袖の声であり、舞台上の俳優には加えない。

Stage Sketchの直接import形式ではない。構図と人物の向きを確認するための資料であり、実寸や上演時間、実際の殺陣・サーカス動作は未確定。自動再生は行わない。

添付画像の舞台段差・花道・客席形状は今回の作品の指定ではないため、図の表示方法だけを参照した。

名前のある人物は `layouts.json` の `familyPalette` を優先して色を決める。ロミオ側（ロミオ、ベンヴォーリオ、マーキューシオ、モンタギュー）は赤、ジュリエット側（ジュリエット、ティボルト、乳母、キャピュレット）は青。匿名の群衆は中立色のままで、冒頭の四隅の乱戦を両家の色で分けないという指定を守る。

`masqueradeInterior` は `RJ-COND-01-C` と `RJ-COND-01-D` にだけ適用する。全員の人物記号にマスクを加え、舞台奥へ中立のバー・カウンターと背面棚を描く。バーは室内の宴を示すセットで、家の所属や立ち位置の区分には使わない。

## サーバー不要の保存版 · 2026-09-10

本人の「オフラインになってしまったのでHTMLで残す」という依頼に対応し、`ロミオとジュリエット_舞台構成図_オフライン.html` を作成。このファイルだけをコピーし、ブラウザで開けば閲覧できる。28フレーム×2方向のSVG、位置データ、全体構成、第2場面台本を埋め込み済み。PNG・SVG・位置JSONの保存も通信不要。

全体構成と第2場面台本は「図に戻る」で閉じられる閲覧窓に収録。旧12場面版や過去の演出ノートへのリンクは収録外として無効化してあり、原本ファイルはそのまま残している。演出メモそのものを削ったり更新したりした保存版ではない。

再生成は通常の図・全体構成・第2場面台本を更新した後に `python3 build_offline.py` を実行する。単体HTMLはその実行時点の保存版であり、自動同期はしない。
