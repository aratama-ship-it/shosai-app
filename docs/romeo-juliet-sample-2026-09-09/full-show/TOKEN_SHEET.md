# 通し上演稿・設計メモ

2026-09-11 / design-web

## 目的と構成

- 本人がショーを最初から最後まで読み、あとから言葉と転換を推敲するためのローカルHTML。
- 既存の3場面・19キューと舞台構成図を継承する。既存の紙色、赤／青の役の色、明朝見出しを参照する。
- 台詞と身体の流れを主表示にし、技術メモと図は開いて読めるようにする。役の動き・転換は台詞だけ表示以外では隠さない。
- 台本の連続表示／キュー表／カード式を比較し、連続表示に進行一覧を添える。詳細な提案を既決定と誤認しないよう、追加の台詞・ト書き・技術案の由来を表示する。
- 単体HTMLでネット接続なしの閲覧、印刷、全文JSON保存に対応。本人の校正を勝手に書き換える編集・保存機能は足さない。
