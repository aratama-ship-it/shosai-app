旧場面01 + 02

大場面 01

対立の街、仮面の出会い

旧01｜二つの家、二つの群れ旧02｜仮面の宴と出会い

この場面で変わること家同士の争いしかなかった世界に、ロミオとジュリエット個人のつながりが生まれる。

内部キュー

  1. 四隅の乱戦

    10名全員。四隅で四組が乱闘し、中央のベンヴォーリオとティーボルトだけが見つめ合う。約3分の既存ブロッキングを維持する。

  2. 最初の一手と暗転

    最後の一組が止まり、中央の二人が動いた瞬間にブラックアウトする。

  3. 仮面の宴

    暗転の中で全員が仮面へ移行。右斜め手前にロミオとジュリエットのスポットを作り、ほかの8名は別の場所で宴を続ける。

  4. 敵の名

    二人が互いの家名を知る。宴の群れが両家の世界を再び二人の間へ持ち込む。

引き継ぐ演出

  • 四隅の乱戦
  • 中央と全体の照明の棲み分け
  • 右斜め手前の二人へのスポット
  • 仮面の群衆

まとめられる理由

冒頭の対立を説明で終わらせず、その直後に生まれる二人のつながりと一つの落差として見せられる。

旧場面03 + 04

大場面 02

窓辺の約束、秘密の結婚

旧03｜窓辺の約束旧04｜秘密の結婚

この場面で変わること偶然の出会いが二人の選択となり、その選択が誰にも知られない結婚として現実になる。

内部キュー

  1. 二人だけの窓辺

    第1場面と同じ右斜め手前の位置を使う。仮面の人々は消え、ロミオとジュリエットだけが残る。

  2. 約束から移動

    二人の約束を合図に中央へ焦点を移し、ロレンス修道士が現れる。

  3. 秘密の結婚

    ロミオとジュリエットが後から中央へ入る。ほかの出演者は背中を客席へ向けて並び、誰にも見られていない秘密を身体で示す。

引き継ぐ演出

  • 右斜め手前の二人
  • 中央のロレンス修道士
  • 背中だけを見せて並ぶ出演者

まとめられる理由

約束と結婚は一つの選択の始まりと完了であり、同じ場面の焦点移動として連続させられる。

旧場面05 + 06

大場面 03

決闘、追放、夜明け

旧05｜決闘と復讐旧06｜追放と夜明けの別れ

この場面で変わること秘密の結婚で争いを避けようとしたロミオが、マーキューシオの死によって報復へ転じ、ジュリエットと同じ場所にいられなくなる。

内部キュー

  1. 追跡と見失い

    ロミオはティボルトを無視して去る。ティボルトは追うが見失う。

  2. マーキューシオの決闘

    そこへマーキューシオが現れ、ティボルトと戦う。台詞を絞り、追跡と戦いを行動で見せる。

  3. 死と即時の報復

    マーキューシオが倒れた瞬間にロミオが戻り、ティボルトへ報復する。

  4. 追放から夜明けへ

    判決を短い声または群れの反応で示す。光を夜明けへ移し、一夜だけ再会した二人が別れる。

引き継ぐ演出

  • 追いかけて見失う流れ
  • マーキューシオの死
  • その瞬間の報復
  • 夜明けに離れていく二人

まとめられる理由

決闘の結果が追放と別れを直接生むため、因果を切らずに一つの下降として見せられる。

旧場面07 + 08 + 09 + 10

大場面 04

望まない結婚、仮死、届かない手紙

旧07｜望まない結婚旧08｜死を装う計画旧09｜薬を飲む夜、葬送の朝旧10｜届かない手紙

この場面で変わること追い詰められたジュリエットが仮死の策を選ぶが、知らせの失敗によって救済の計画が破局への道へ反転する。

内部キュー

  1. 二人だけの圧力

    ジュリエットとキャピュレットの二人だけ。客席右のキャピュレット側で、望まない結婚を迫る。

  2. 薬と計画

    中央のロレンス修道士が仮死の薬と手紙の段取りを示す。ロミオは追放先にいて不在。

  3. 仮死と葬送

    ジュリエットが薬を飲んで仮死状態になる。祝いへ向かう身体の配置が、発見を境に葬送へ変わる。

  4. 届かない知らせ

    手紙を届ける人とロミオが入れ違う。追いかけっこの感触を、ジャグリングや受け渡しなどサーカス的な反復で比喩化する。

引き継ぐ演出

  • 客席右のキャピュレット家
  • ジュリエットとキャピュレットの二人
  • 仮死の薬
  • 使者とロミオの入れ違い
  • サーカス的な追いかけっこ

まとめられる理由

圧力、計画、実行、伝達失敗を一本の装置として見せると、手紙が届かないことの重さが短い上演でも伝わる。

旧場面11 + 12

大場面 05

墓所、二人の死、残された和解

旧11｜墓所でのすれ違い旧12｜残された人々と和解

この場面で変わること再会の時間が合わず二人は死ぬ。その不在を前に、残された人々が初めて一つの場所へ集まる。

内部キュー

  1. 同時にある二つの場所

    舞台左に墓所、右に別の場所を作り、中央は人の身体による川として互いに干渉できない領域にする。

  2. 時間のすれ違い

    ロミオがジュリエットの目覚め前に死ぬ。ジュリエットが目覚め、ロミオの死を知って後を追う。

  3. 川がほどける

    二人の死の後、人の川が止まり、境界を作っていた出演者が一人ずつ離れる。

  4. ロレンスを中心に集まる

    ロレンス修道士を中央に置く。悲しみの中で一人ずつ人が集まり、最後に両家の父が和解する。

引き継ぐ演出

  • 舞台左の墓所
  • 舞台右の別の場所
  • 人の川による非干渉領域
  • 中央のロレンス修道士
  • 一人ずつ集まる終幕

まとめられる理由

二人の死と和解の間に新しい場面転換を置かず、死の結果として人々が集まる流れをそのまま見せられる。

5場面を下限とする理由

五つの取り返せない転換を一場面ずつ受け持たせる。これより少ないと、決闘の結果か、仮死計画と手紙の失敗の因果が一つの場面に詰まり、観客が物語を追いにくくなる。

外す境界代わりに使うつなぎ
旧01 + 02ブラックアウト後、同じ大場面内で仮面の宴へ転換
旧03 + 04右斜め手前から中央へフォーカスを移動
旧05 + 06判決の短い声と光の変化で夜明けへ連結
旧07 + 08 + 09 + 10場所のゾーンと道具の受け渡しで連続
旧11 + 12人の川がほどけ、そのまま中央へ集まる
