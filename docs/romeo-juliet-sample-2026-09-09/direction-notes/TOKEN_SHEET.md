# 演出ノートの表示仕様

本人が会話の続きを考えながら、場面別に読み返すためのローカルノート。下訳と同じ紙色を使い、演出の要約の下で短い台詞と具体的な演出を見比べる。発言原文と自動生成用の項目は詳細へ収める。場面ごとのノートと発言順のログを比較し、通常表示は場面別、発言順は原文履歴として残す。専門ツールの設定操作は持たせず、12場面への追加を妨げない。未記入の場面も見出しを開けば台詞を読める。

- 読み手と用途: 本人の演出メモ確認、後続エージェントの場面生成。
- 読後の状態: 何を言ったか、何がまだ決まっていないかが分かる。
- 固有の核: 四隅の乱闘から中央二人の戦いへ、群衆の停止を境にフォーカスを一度で受け渡す。
- 継承: 既存下訳の紙面と語彙。場面の具体的内容を見出しの下へ置く。
- 条件: PC/390pxで読める。JSONとHTMLの内容を同じ正本から生成する。
- 上演人数: 10名。現在の名前のある10役を一人一役で担当し、各場面で名前のある役を演じていない出演者がアンサンブルを兼任する。俳優名と役の割当は未決定。
- 共通配置: 客席から見て左をモンタギュー家、右をキャピュレット家の基本領域とし、場面固有の指定がある場合はそちらを優先する。
- 第1場面: 共通配置を適用せず、左右で両家を表さない。基準舞台は間口12m×奥行9m。中央のベンヴォーリオとティーボルトだけを名前のある役として扱い、ほかの8名は各役の俳優が匿名の群衆を兼ねる。奥左はロミオ役×ジュリエット役＝和解、奥右はロレンス役×ジョン役＝和解、手前左はモンタギュー役×キャピュレット役＝双方がダメージ、手前右はマーキューシオ役×乳母役＝双方がダメージで最後まで動く。0:00〜1:55は四隅同時、1:55〜2:35は三組が順に収束、2:35〜3:00は六人の散開と最後の一組、3:00で中央の最初の一手と即ブラックアウト。約3分で、座標・動線・秒配分は未稽古の仮案。
- 第7場面: ジュリエットと父キャピュレットだけを舞台右側に置き、母・乳母・パリス・アンサンブルは出さない。
- 第10場面: ジョン修道士は手紙を持って左へ、ロミオは左から右の墓所へ進み、舞台中央で互いに気づかず入れ違う。台詞なしの8行で簡略化する。
- 第10場面の追いかけっこ: 人が人を直接追う芝居にはせず、相似するサーカスの移動フレーズを時間差で重ね、動きが動きを追う比喩として見せる。中央では時間差または高低差で接触を外す。具体的な技は未決定。
- 第11場面: 客席から見て左に墓地・墓所、中央に左右が干渉できない領域、右に別の場所を置き、二つの出来事を同時進行させる。墓所の左配置は共通配置より優先する場面固有の指定。右をロレンス修道士の準備場所または移動経路とする案は未決定。
- 第11場面の非干渉領域: 中央の複数のアーティストが、川のように前の動きを受け取りながら流れ、左右の人物の歩みや身振りを元の岸へ返す。人の身体を主表現とし、装置は補助または別案とする。即興でも「流れる・受け止める・向きを変える・岸へ返す」の動詞、対岸へ運ばない等の禁止、開始・返流・解除のキューは固定する。人数、幅、流れの方向、接触、解除動作は未決定。
- 第11場面の別案: 舞台上の約束、光と音、紗幕、影・残像、回り舞台、空白を橋へ変える解除キューの6案を、設備負担・今回への転用・注意・出典つきで比較する。人の川を補助する場合も含め、6案は未採用として表示する。
- 第12場面: ロレンス修道士を舞台中央に置く。ロミオとジュリエットの死を先に見せ、人々が悲しみながら一人ずつロレンスの周囲へ加わる。喪失と真相を共有する過程を経てから、両家の父が手を差し出す短い台詞へ進む。人物構成、登場順、集合経路、説明の台詞量、第11場面の人の川からの転換は未決定。
