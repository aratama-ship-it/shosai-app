# ロミオとジュリエット M6転換・採用済みサンプル

「中央の制止と挑発」から「仮面舞踏会と二人の出会い」へ移る暗転転換を、Stage Sketchで確認できる隔離サンプルにしたものです。既存の全体サンプル、製品コード、ブラウザの保存領域は変更しません。

## 状態

`ai-proposal.json` は、本人が確定したM6の12判断を土台にしたAI提案原本です。2026年9月12日、本人がM6-C1〜C3をすべてAと回答し、配置、バー固定後の仮面装着、3枚構成を **サンプルとして採用** しました。回答は `owner-approval-2026-09-12.json` に分離して記録し、AI提案原本は書き換えていません。

この採用はサンプル内の設計判断です。実在の演者、会場経路、バーの寸法・重量・固定、工程時間、転換締切、安全性を確定しません。

既存資料には「俳優10名とは別のスタッフがバーを設置」「転換込み20秒」という古い仮案が残っています。この候補では、後から受領した本人判断を優先し、ロレンス修道士担当とジョン修道士担当が右袖から一体型バーを運ぶ形へ置き換え、時間は未計測に戻します。元資料自体は書き換えません。

## ファイル

- `ai-input.json`: 別のAIへ渡せる自己完結した入力。確定事項、既存資料との矛盾、AIが提案してよい範囲、出力条件を分離。
- `ai-proposal.json`: 今回のAI提案。Q02の事前位置、暗転中の3配置、Q03のバー係位置を収録。
- `owner-approval-2026-09-12.json`: M6-C1〜C3の本人回答Aと、採用範囲・未承認範囲の記録。
- `build_candidate.py`: 元の全体サンプルへ提案を機械的に適用し、別ショー用JSONと確認HTMLを生成。
- `romeo-juliet-m6-transition-candidate.stage-sketch.json`: Stage Sketchで「別のショーとして開く」採用済みサンプル。
- `index.html`: 5枚の配置図、確定／提案／未確認の区別、判断ボタン。
- `validate_candidate.mjs`: 元データ不変、配置順、担当、バー位置、仮面数、null時間、参照整合を検査。

## 再生成と検査

```sh
python3 build_candidate.py
node validate_candidate.mjs
```

ブラウザへの読み込みは `browser_check.py` を使い、隔離したブラウザコンテキストで確認します。本人の現在のショーへは書き込みません。

この3枚は客席へ見せる場面ではなく、暗転中の工程を確認する技術図です。現行Stage Sketchには複数の技術図を客席表示から除外したまま一つの暗転内で自動進行する機能がないため、本番用のGO送受信や自動実行には使いません。
