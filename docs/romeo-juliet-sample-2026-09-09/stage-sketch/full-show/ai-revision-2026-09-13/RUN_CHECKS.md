# AI showwright for StageSketch — 一周点検

このフォルダで実行します。元サンプル・製品本体は編集しません。

```sh
python3 build_revision.py
python3 run_checks.py
```

生成だけを検証する場合は `python3 build_revision.py --check`。4生成物をバイト単位で比較し、書き換えません。入力4ファイルのハッシュが変わると生成を中断します。内容を再確認せず期待ハッシュだけ更新しないでください。

一括検査は内部ショーデータの意味検査、Python / JavaScript回帰検査、ネイティブ構造検査、隔離ブラウザへの「別のショーとして開く」、全シーン移動時のcanvas描画、390px / 1440px表示、JSON保存、検査後の再現性を確認します。回帰件数はテスト出力から集計し、固定値を表示しません。各スクリプトは単独でも実行できます。ブラウザ試験はローカルNode・Playwright・Chromiumとloopbackへのbind許可が必要です。依存の自動インストールはしません。必要なら `SHOWWRIGHT_NODE` と `NODE_PATH` でランタイムを指定してください。

## 今回の修正

- Stage Sketch非依存の `romeo-juliet.showwright.json` と、厳格な `showwright-core.schema.json` を追加。演出内容、判断、出典、未計測値、制約を製品形式から分離。
- 判断状態を「著者」「サンプル採用」「実舞台検証」「本番承認」の4軸に分離。成果物への収録だけで承認状態を上げません。
- M6を含む宣言済みの全制約をコア側で検査し、主要な一項目破壊試験を追加。
- 全場面の照明目的とM6技術工程をPython直書きからコアデータへ移し、変換後Stage Sketch JSONのバイト列を維持。
- 到達しない旧Pythonブラウザ実装を除去。実行入口を薄くし、検査本体をJavaScriptに統一。
- 入力4件のハッシュ固定、全4生成物の再現性検査、HTML置換トークンの検証を追加。
- 意味上の変更台帳に加え、JSONの項目別before/afterを `ai-field-changes.json` に出力。ID基準の監査形式でありJSON Patchではありません。
- 全シーンの入力に明示された主要配置・形状・リンク・時間を読込後に照合。各シーンで平面canvasが生成されることも確認します。すべてのJSON属性が無変化という保証ではありません。
- 実行開始・失敗時にもレポート状態を更新し、過去のPASSの取り違えを防止。
- 形状の独自イラスト、使わないA/B/C用CSS、出力値の一部二重管理を除去。比較は製品の実描画画像を使用。

## 見つかった既存仕様と境界

装着・手持ちの小道具は、Stage Sketchの `refreshBases` が演者の顔・手に追従させます。仮面の入力座標と読込後座標が異なる場合があります。この既知の追従は `heldPlacementAdjustments` に記録し、人物・独立セットの意図しない配置変更とは区別します。追従先・装着モードは一致検査しますが、人体リグ計算の正しさ自体はこの検査の対象外です。

検査対象はこのサンプルの生成・読込経路です。Stage Sketch全機能のリファクタリング、実公演での安全性・搬入可能性の確認、本人による形状採用判断は行っていません。ローカルAPIはモック、Service Workerは無効、利用者のブラウザ保存領域とは分離しています。

内部形式の28本編シーンとM6転換内の技術状態3枚を、Stage Sketch変換時に31シーンへ展開します。`generatedAt`は再現性のある成果物版時刻で、実行時刻ではありません。実際の検査時刻は各QAレポートの`checkedAt`です。

構造・ブラウザ検査は製品ファイルのハッシュを記録します。他セッションの変更を検出した場合は失敗させ、巻き戻しません。結果の有効範囲はレポート記載の対象ハッシュと時刻です。

成果物改訂前の退避は `qa/pre-refactor-2026-09-13.tar.gz` に残しています。この一周点検によるショーJSON本体の変更はありません。復元操作は行っていません。
