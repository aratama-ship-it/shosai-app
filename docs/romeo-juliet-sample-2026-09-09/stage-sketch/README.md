# 第1場面 Stage Sketch 下書き

`scene-01-stage-sketch-v3.json` は、演出ノート `RJ-DIR-01` と `direction-notes/scene-01-blocking-plan.json` から生成した Stage Sketch version 3 の読み込み候補です。12m×9mの基準舞台上に、四隅の4組と中央の2名をA〜Dの4キューで配置する約3分の仮案です。

中央のベンヴォーリオとティボルトだけが名前のある役として登場します。ベンヴォーリオは乱闘を止めようとし、ティボルトはその制止を挑発へ変えようとします。剣が触れる前の瞬間で暗転します。ほかの8名は各役を担当する俳優の識別名を使いますが、この場面では匿名の街の群衆役です。俳優の身長は未提供のため、JSON内の165cmは表示用の仮値です。

生成:

```sh
python3 build_scene_01.py
node validate_scene_01.mjs
```

検証はv3スキーマ、10名、4キュー、180秒の仮配分、最終キューのアクション発火・即ブラックアウトを確認します。動線警告は意図したものです。座標と動線は演出検討用で、安全間隔や衝突回避を保証しません。

このJSONは生成・スキーマ検証済みですが、ブラウザ内のStage Sketchへは取り込んでいません。本人が内容を確認し、実会場と俳優条件に合わせた後に読み込む前提です。
