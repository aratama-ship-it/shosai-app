# Twelve short scene samples

Purpose: 12の構成パートに対し、各10行前後の分かりやすい翻訳抜粋を読む・修正する。第5場面は台詞3行・ト書き7行とし、決闘から復讐までの因果関係を行動中心で見せる。全文翻訳や連続した上演台本を作らない。
User direction: 劇のニュアンスを残す。文章は部分的に分かりやすい箇所を10行程度。第5場面は長くしすぎず、台詞を減らして行動を増やす。ティボルトの挑発をロミオが無視して去り、ティボルトが追って見失った後にマーキューシオが現れて戦う。ロミオはマーキューシオの負傷を見た瞬間に報復する。最終推敲は本人。
Scene6 content: 鳥の声をめぐる冒頭だけで終えず、夜明けの受容、実際の別れ、再会への問い、墓の予感までを11行で示す。
Scene7 content: ジュリエットと父キャピュレットだけの10行で、拒絶、命令、懇願、勘当の宣告までを示す。原作で同席する母と乳母の不在は注記する。
Scene10 content: 感染による未配達の説明を、手紙を届けに向かうジョン修道士とヴェローナへ戻るロミオの入れ違いに置き換える。台詞なし・ト書き8行。原作との差は注記する。
Design: 既存の紙色を継承し、日本語を主表示、英語原文と場面全体の説明を折りたたむ。全12場面へ一覧から移動できる。省略注は台詞の外へ常に表示。
