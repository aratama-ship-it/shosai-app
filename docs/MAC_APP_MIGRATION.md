# ブラウザから「制作の書斎.app」へ記録を移す

ブラウザに保存されているショー、スクラップブック、制作机に関係する端末内の記録を、
一つのJSONファイルにして「制作の書斎.app」へ移す手順です。移行操作は自分で行います。

## 先に知っておくこと

- ブラウザ版とMacアプリ版は同じ画面ですが、端末内の保存場所は別です。
- `file://` で開いた書斎と、GitHub Pagesなどの `https://...` で開いた書斎も、保存場所が別です。
  記録を作ったときと同じ開き方・同じブラウザで、書き出してください。
- JSONには `shosai-` / `stage-` で始まる端末内の記録だけが入ります。ほかのWebアプリの
  localStorageと、名簿の合言葉は入りません。
- 読み込みでは、ファイルに入っているキーだけを上書きまたは追加します。ファイルに無い既存データは
  削除しません。実行前に、復元する件数・上書きする件数・追加する件数が表示されます。

## 1. ブラウザ版から書き出す

1. これまで記録を作っていたブラウザで、制作の書斎の `index.html` または公開URLを開きます。
2. 上部メニューの「スクラップブック」を開きます。
3. ページ操作の列にある「端末データを書き出す」を押します。
4. 保存先を選び、`制作の書斎-端末データ-YYYY-MM-DD.json` が保存されたことを確認します。

このファイルには、同じ保存場所にある複数のショー、舞台スケッチの設定、スクラップブックの
現在の紙面・保存済み紙面、場面問答など、対象接頭辞の記録がまとめて入ります。

## 2. Macアプリへ読み込む

1. `mac-app/build/制作の書斎.app` を開きます。
2. 上部メニューの「スクラップブック」を開きます。
3. 「端末データを読み込む」を押し、手順1で保存したJSONを選びます。
4. 確認画面に出る「復元する件数」「上書きする件数」「追加する件数」を読みます。
5. 内容に問題がなければ「OK」を押します。キャンセルした場合は何も書き込みません。
6. 完了後に画面が自動で読み直されます。舞台スケッチとスクラップブックを開き、記録を確認します。

複数のブラウザや複数の公開URLに記録が分かれている場合は、保存場所ごとにJSONを書き出し、
Macアプリへ順番に読み込みます。同じ保存キーは後から読み込んだファイルの内容で上書きされるため、
確認画面の上書き件数を必ず確認してください。

## 3. 名簿の合言葉を初回だけ入れ直す

名簿の合言葉 `scout_pass` は、セキュリティ上、移行JSONへ入れません。また、合言葉の保存場所は
オリジンごとに別です。Macアプリで初めて名簿を開くときだけ、ブラウザ版と同じ合言葉をもう一度
入力してください。一度正しく解錠すれば、以後はMacアプリ側の保存場所に記憶されます。

## 読み込めないとき

- 「JSONとして読み取れません」: ファイルが途中で壊れていないか、別のJSONを選んでいないか確認します。
- 「kindが違います」: 舞台スケッチ単体やスクラップブック1紙面のJSONではなく、
  `制作の書斎-端末データ-...json` を選びます。
- 「versionが違います」: 書き出した側と読み込む側の制作の書斎を同じ版へ揃えてから、もう一度書き出します。
- 読み込みをキャンセルした: データは変更されません。同じファイルを選び直せます。
