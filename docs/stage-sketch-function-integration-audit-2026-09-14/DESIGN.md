# 監査資料の設計ノート
用途: 本体を改修する前に、所有者が全体構造・根拠・修正順を判断する。対象は舞台制作の利用者と次回実装担当。
固有の核: セクション→音源→シーン→転換→キュー→再生→保存という制作工程を先に見せる。一般的な管理画面のカード壁を避け、舞台の進行表として読める見出し、罫線、根拠番号を使う。
外部ライブラリ・外部フォントなし。ローカルで開ける単一HTML。検索・優先度・分類フィルタは資料内だけで動作し、保存領域やアプリに書き込まない。
