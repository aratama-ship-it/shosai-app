04 / FINDINGS

不足・断線・重複・衝突：32の論点

ブラウザ再現は隔離した合成データによる観測。ソース確認は条件と分岐を追った判断。未検証は疑い・設計リスクであり、発生を断定していない。P0は無条件の全面障害を意味せず、各項目に示す条件での優先度。

P0A01 · 確認済みの不具合ブラウザ再現

旧データの控え保存に失敗しても、次の操作で自動保存される

条件 未セクション化の旧データで、移行前バックアップキーへの書き込みだけが容量不足で失敗する。

初期化は「変換後の自動保存を止めました」と表示するが、persistSoonに保存停止状態が渡らない。合成データで、シーンを切り替えると控え0件のまま保存内容が scene×2 から section＋scene×2 に変わった。

影響 移行前の原文を保全するという約束が破れる。実ユーザーデータの消失を観測した、という意味ではない。

根拠と次の判断 · A01

保存停止状態を全保存入口で共有する設計と、失敗注入テストを先に固める。修正する場合も移行を自動で再実行しない。
