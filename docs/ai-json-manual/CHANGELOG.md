# CHANGELOG

## v0.2.5 互換確認 — 2026-09-13

- 舞台スケッチ v0.3.6 の現行定義から会場・駒・姿勢を再抽出し、生成規則と49件の回帰検査が一致することを確認。規則内容は変えず、対応アプリ版の表記だけをv0.3.6へ更新。
- 配布ページの名称を「AI showwright for StageSketch」へ統一。本文をプロンプトとしてダウンロード／コピーする既存機能と、ブラウザ内JSON点検を維持。

## v0.2.5 — 2026-09-11

- 本人確定の二段階点検を反映。MDは生成・自己点検、ページは申告に依存しないJSON実体の独立検査。共通規則は判定器からの導出部分と照合し、SELF_CHECKも本文と一致を検査する。
- 許可種類の限定、色/backgroundの型、文章長、階層、重複登録参照、登録装置size、不正オブジェクト、キー重複、容量/構造上限を点検。「図・内容が変わる可能性」「生成仕様への違反」と「点検不能」を分離。
- 入力変更時に古い合格・修正依頼・コピー退避欄を無効化。ファイル読み取り失敗、非同期読み取り競合、クリップボード失敗、検査例外を明示し、JSONを自動修正しない。
- CLIとページで文字列の解析から判定まで共用。ビルドは出力フォルダを削除せず、--checkで正本と生成物を読み取り限定照合する。会場は正規表現ではなく隔離環境で評価した本体定義を使う。
- 本体・ゲスト公開設定・MCPは変更しない。AI再試験・実機確認・公開は別途。

## v0.2.4 — 2026-09-11

## v0.2.3 — 2026-09-11

- 本番P2（Gemini）で全 color の先頭に空白が入り、ブラウザが黙って既定色へ置き換えた（全演者が同色に）。自己点検表に「先頭・末尾に空白を入れない」と結果を明記。

## v0.2.2 — 2026-09-11

- 本番P2（ChatGPT 無料版・ログインなし）で、模擬P2と同じく「依頼にない lightingIntent を全場面に足す」が再現（2AI・3本中3本）したため、「求められていない任意項目を足さない」を契約表の直下と自己点検表へ追加。

## v0.2.1 — 2026-09-11

- 模擬P2（履歴なしの Sonnet に本文だけを渡す試験）の結果を反映。質問候補の「section分け」と「照明」を分離し、照明は「駒（図に描く）」と「lightingIntent（文章のみ）」の区別を質問時に明示するようにした（模擬試験で1問に混ざり、依頼者の意図と違う解釈になった）。ショー全体に効く仮定は最初の scene の note に一度だけ書く、と明記。

## v0.2.0 — 2026-09-11

- 「足りない情報の聞き方（質問票）」を追加。結果を大きく変える未確定事項（人数・会場と規模・場面数・道具と高リスク装置・題材と採用済み要素・section/照明）だけを、推奨＋理由＋A/B/C＋保留／別案 の形式で1回にまとめて聞き、回答後はJSONだけを返す。保留は推奨案で仮採用し scene.note に「仮定:」を残す。本人の判断シート（推奨・保留・別案・補足）の形式に揃えた。

## v0.1.1 — 2026-09-11

- 会場と規模の組を訂正: `endstage` はアプリに存在しないため削除。規模は会場ごと（proscenium=small/mid/large, thrust=small/mid, arena=onering/grand, blackbox=small/mid）。標準見本の blackbox+large を mid へ修正（ブラウザ往復検査で small に化けたため）。
- 姿勢46語を本文に列挙し、AIが外部ツールなしで自己完結できるようにした。自己点検表を本文へ全文同梱。
- 検査器 `tools/ai-json-check.mjs` が会場ごとの規模を stage-venues.js から読んで検査するようにした。
