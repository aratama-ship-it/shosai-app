# 仕様書: セクション色バー・全開閉・後からまとめる・合計時間（2026-08-16）

対象アプリ: 舞台スケッチ（`index.html` + `stage-sketch.js` + `style.css` + `stage-i18n.js`）

## 共通の制約（必ず守る）

- ファイルの削除・移動はしない。既存ファイルは編集前に必ず読む。
- 既存機能（シーンのドラッグ並び替え・深さ変更、セクションの開閉、シーン一覧グリッド、
  アンドゥ、保存/読込）を壊さない。
- 追加する日本語UI文言は `stage-i18n.js` の対訳テーブルへ英訳を追加（`announce()` の文は `SAY` 側の正規表現テーブル）。
- CSSは `style.css` に追記。配色は既存の落ち着いた茶系に合わせ、彩度の高い色は使わない。
- コメントは既存ファイルの流儀（日本語・理由を書く）で。

## 背景（現状の構造）

- シーンは `state.project.scenes` のフラット配列。各行に `depth`(0〜`MAX_DEPTH`=4)、
  `kind: "scene" | "section"`。セクションの中身＝直後に続く depth が大きい行。
- 一覧は `renderScenes()`（10695行付近）。行のインデントは `row.style.marginLeft = depth*14px`。
- 開閉は `state.closedSections[sectionId]`、判定は `sceneHidden(i)` / `sceneHiddenIn(list, k)`。
- グリッドは `renderSceneGrid()`。セクションは `h3.stage-scene-grid-section`。
- セクション追加は `addSection()`、行名変更は `openRename(scene)`。
- シーンの時間: `scene.rehearsal.holdDurationSeconds` / `.transitionToNextSeconds`、
  機能フラグ `featureOn("sceneTiming")`。

## 機能A: セクションの色バー（Logicのフォルダ風）

### 色の決め方

- 8色の控えめなパレットを定義（例。多少の調整は可）:
  `["#d3ac59","#a84b26","#77865f","#5f7386","#7a5a6e","#4f7a72","#b98d5a","#8a8177"]`
- セクションの色は **id の簡単なハッシュ % 8** で決める（保存しない。並び替えても安定する）。
  `function sectionColor(id)` として共通化する。

### 一覧での描き方

- 行の `style.marginLeft`（depth*14px）を廃止し、代わりに行頭へ **色バー用の溝**
  `span.stage-scene-bars` を置く。溝は `depth * 14px` 幅で、深さ1段=14pxのスロットに分ける。
- 各スロット d (0..depth-1) には、その行の**深さ d にある祖先セクション**の色の縦バー
  （幅3px・高さ100%・角丸1px）を描く。祖先が「シーンではなくセクション」のときだけ描く。
  祖先の探し方: 配列を上へ遡り、depth が d の直近の行がセクションならその色。
- セクション行自身は、自分の深さのスロットに**自分の色のバー（幅5px）**を置く
  （子よりわずかに太くして「ここが親」と分かるようにする）。
  さらにセクション名の左に小さな色チップ（8px角・角丸2px・自分の色）を添える。
- 実装は `renderScenes()` の行生成部で、深さごとの「いま効いているセクション色」の
  スタックを持ちながら1パスで作る（行ごとに配列を遡り直さなくてよい）。

### グリッドでの描き方

- `h3.stage-scene-grid-section` に、その色の **左ボーダー4px** を付ける。

## 機能B: すべて畳む／すべて開く

- `index.html` のシーンパネル `.stage-scene-move`（「⊞ 一覧」がある行）へボタンを1つ追加:
  id `stage-scene-fold-all`、class `btn-quiet`。
- 表示は状態で切り替える: 開いているセクションが1つでもあれば「▸ 畳む」、
  全部畳まれていれば「▾ 開く」。`renderScenes()` 内で毎回文言と `title` を更新する。
  （i18n: 「▸ 畳む」→ "▸ Fold"、「▾ 開く」→ "▾ Unfold"。title「セクションをすべて畳む／開く」）
- 動作: 畳む＝全セクション id を `state.closedSections[id]=true`。開く＝`state.closedSections={}`。
  その後 `renderScenes()` + `persistSoon()`。セクションが1つも無いときはボタンを `hidden` にする。
- アンドゥ履歴には積まない（`checkpoint()` は呼ばない。開閉は表示状態であり編集ではない）。

## 機能C: グリッドのセクション見出しで開閉

- `renderSceneGrid()` のセクション見出しをクリック可能にする（`<h3>` の中に `<button>` を置くか
  h3 自体にクリックを付け、`aria-expanded` を設定）。
- クリックで `state.closedSections[id]` をトグル → `renderSceneGrid()` と `renderScenes()` を
  両方描き直し、`persistSoon()`。**一覧側と同じ状態を共有する**（別々の畳み状態を持たない）。
- 畳まれたセクションの中のシーンカードはグリッドに出さない
  （判定は `sceneHiddenIn(state.project.scenes, index)` を使う。ネストも自然に従う）。
- 見出しの先頭に `▾`/`▸` を出す。見出し自体は畳まれていても必ず出す
  （祖先が畳まれている場合はその見出しも出さない）。

## 機能D: 後からまとめる（範囲を選んで新しいセクションへ）

- カーソル行（`isCursor`）が **kind === "scene"** のとき、鉛筆（✎）の隣に
  ボタン `⊂` を出す（class `stage-scene-wrap`、title「ここから範囲をまとめて新しいセクションにする」）。
- `⊂` を押すと**範囲選択モード**に入る:
  - モジュール変数 `wrapPickStartId` に開始行 id を控え、`els.sceneList` に
    class `is-wrap-picking` を付け、開始行に class `is-wrap-start` を付ける。
  - `announce()`: 「まとめる最後のシーンをクリックしてください。同じシーンを押すと1つだけまとめます。Escで中止。」
  - モード中は行チップのクリックを「範囲の終わり指定」として扱う（openScene はしない）。
  - Esc キー、または対象外クリック（下記の不成立条件）で中止し `announce("まとめるのを中止しました。")`。
- 成立条件: 終了行は開始行と**同じ depth** の scene 行で、開始行と同じ並び位置以降にあり、
  間の行はすべて `depth >= 開始行のdepth`（＝同じ親の中の連続範囲。間にあるセクションは中身ごと含む）。
  終了行＝開始行でもよい（1シーンだけまとめる）。
- 実行:
  1. 範囲内のどれかが `depth+1 > MAX_DEPTH` になるなら
     `announce("深さの上限に達するため、ここではまとめられません。")` で中止。
  2. `checkpoint()` → 開始行の直前に新しいセクション（`newScene(タイトル, false, "section", 開始行のdepth)`、
     タイトルは `addSection()` と同じ連番方式）を挿入 → 範囲内の全行（子孫含む）の depth を +1。
  3. `state.cursorRowId` を新セクションに移し、`renderScenes()` + `persistSoon()` 後、
     `openRename(新セクション)` を開いてすぐ名前を付けられるようにする。
  4. `announce("◯シーンをまとめました。")`（数はセクションを除いた scene 行の数）。
- モードの見た目: `is-wrap-picking` 中は行チップのホバー色を変え、開始行にうっすら枠を付ける
  （CSS追加。派手にしない）。

## 機能E: セクション行に合計時間

- 一覧のセクション行の `count`（現在は中の場面数のみ）を拡張:
  `featureOn("sceneTiming")` かつ中の scene 行の
  `rehearsal.holdDurationSeconds + transitionToNextSeconds` 合計が 0 より大きいとき、
  `9・約23分` の形式にする（分は四捨五入。60秒未満なら `9・45秒`）。
  それ以外は従来どおり数だけ。`title` 属性に「9場面・合計 約23分」の形で全文を入れる。
- グリッドのセクション見出しの右端にも同じ情報を控えめな `span` で出す:
  「9場面・約23分」（時間が無ければ「9場面」だけ）。英語は "9 scenes · ~23 min"。
- 合計の計算は `function sectionTotals(index)` として共通化する
  （直下だけでなくネストした子孫の scene も全部含める）。

## 完了条件（検証可能な形で）

1. `node --check stage-sketch.js` と `node --check stage-i18n.js` が通る。
2. セクションを2つ（うち1つは入れ子）作ると、一覧の行頭に色バーが出て、
   同じセクションの中身は同じ色で貫かれる。並び替えても各セクションの色は変わらない。
3. 「▸ 畳む」で全セクションが畳まれ、ボタンが「▾ 開く」に変わる。開くと戻る。
   セクションが無いショーではボタンが出ない。
4. グリッドの見出しクリックでそのセクションのカードが消え、一覧側も同じく畳まれる。逆も同じ。
5. シーン行のカーソルに `⊂` が出る → 押して別の行をクリックすると、範囲が新しい
   セクションに入り、名前変更がすぐ開く。Escで中止できる。深さ上限では安全に断る。
6. 「シーンの時間」ONで時間を入れたシーンを持つセクションに「◯・約◯分」が出る。OFFなら数だけ。
7. 実装後、変更点の要約を本ファイル末尾に「## 実装メモ(Codex)」として追記する。

## 実装メモ(Codex)

- セクションIDのハッシュから8色を決め、一覧へ祖先／自身の色バーと色チップ、グリッド見出しへ同色の左ボーダーを追加した。
- 一覧行へ全セクションの「畳む／開く」を追加し、一覧とグリッドの開閉状態を `closedSections` で共有した。グリッド見出しからも開閉でき、畳まれた祖先配下は見出しを含めて隠れる。
- シーン行の `⊂` から同じ親内の連続範囲を新しいセクションへまとめる操作を追加した。Esc／不成立時の中止、最大深さの拒否、成立時のアンドゥ記録と即時名前変更に対応した。
- セクション配下（入れ子を含む）のシーン数と時間を共通集計し、「シーンの時間」ON時だけ一覧とグリッドへ合計時間を表示するようにした。
- 新しい固定UI文言とアナウンス文を `stage-i18n.js` へ日英対訳として追加した。
- `node --check stage-sketch.js`、`node --check stage-i18n.js`、`node --test tests/*.test.mjs`（243件）を実行し、すべて通過した。
