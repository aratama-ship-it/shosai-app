# 人物別予定表の試作：設計メモとトークン

2026-09-09。対象people-plan-trial-2026-09-09.html / people-plan-ui-2026-09-09.mjs。
既存shared-contractとhandoffの紙色・手順表を継承。設計ルールはdesign-webに従う。

## 5つの整理

1. 本人/舞台監督が、出番の変更と転換の担当・所要の関係を局所例で確かめる場面。
2. 数字を変えた結果が図と原因へつながり、元の条件へ戻れることを目標にする。
3. 核は出番終了→袖の移動→担当交代、相手を待っている人物、開始に必要な合図。
4. 契約の長文を操作面へ移す案を外し、条件→人物の図→警告の原因→元の予定の順で構成する。既存の紙色・罫線を継承し、人物別に無関係な色を増やさない。
5. 人物3人・転換1回、再読込みで初期化、編集は可逆、予定外の空きを保証しない。元の承認済み試作/製品コードを保持。

- 入力は3列、680px以下1列。各操作44px以上。数値入力は0.1秒刻み、空欄は未定。入力不正時は旧結果を有効な判定として残さない。
- 図は1秒48px、左側人物名100px、右余白48px、上の目盛48px。最小図幅1000px。下余白32px。

- 作業はpaper塗り/ink文字、移動はpaper枠2px、待機はpaper破線2px（4/4）。未定の終端を勝手に図の右端まで伸ばさず、図外の未定一覧に時刻範囲を出す。
- 図は画像として読み、操作は別の44pxボタン/予定表で行う。警告の「関連する予定を見る」で詳細と図の関連帯を強調。狭い帯へ小さなクリック対象を置かない。
- 履歴はメモリ上で最大20操作。プリセット・元に戻すあり。保存/本番GO/アニメーション/製品読込みなし。

## 今回の編集範囲

出番終了0〜20秒、Q13と締切0〜60秒、机を置く所要0.1〜20秒。すべて空欄は未定。
追加作業は6〜9秒に固定し、担当なし（未追加）/A/B/C/担当未定を選ぶ。交代後の相手はC/未定を切り替え、持直し・合図待ち・搬出・到着待ちの対象範囲を明記する。別担当へ自動で経路を作り直す機能は今回含めない。
入力はchange時に反映し、入力途中の誤った値を確定所要にしない。入力不正時は時刻比較と図を保留し、入力修正と取消しを使えるようにする。

## r2の文言調整

Fableレビューを受け、未知の時刻は「開始未定」「終了未定」と表示する。既知側だけに秒を付け、「10秒〜終了未定（未確定）」のように読む。「開始未定」「終了未定」「（未確定）」は既存のkeep指定で語中改行を避ける。数値・配色・レイアウトのトークンは保持。既存の「試作の記録」内にレビュー対象版と反映版を区別した短い説明と記録へのリンクを置く。
