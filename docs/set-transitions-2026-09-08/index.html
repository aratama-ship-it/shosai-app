初版で決めておく操作

転換を開くとき

  • 隣接する場面の間から開く。搬出・搬入・移動・回転の候補が並ぶ。
  • 同じ位置へ戻す作業や途中待機は「手順を追加」で補う。
  • 候補は下書き。担当・袖・秒数が不明なら「未定」を保つ。

変更するとき

  • 同時作業を同じ手順にまとめ、次は全作業の終了後に進める。
  • 経路だけを直す。到着位置の変更は到着場面を編集する。
  • 場面の順番を変えたら、転換を保持して「接続の再確認」を出す。

図と担当表は同じ転換データから作ります。転換の見積もり秒数を、既存の稽古時間へ自動反映するのは初版では保留します。

実装は、小さな1転換から

  1. 固定例で操作を判断。 机の時間変更、途中停止、合図待ち、転換表を確かめる。今回の資料はここまで。
  2. 実際の1転換へ置き換える。 使用端末、演者と転換担当の兼務、袖で使う表の列を合わせる。
  3. 製品へ組み込む。 搬入出・回転・手順編集・保存・Undo・平面/3Dの共通再生・印刷を一巡させる。

次段階に残すもの：吊物・せり・盆との連動、任意の複雑な依存関係、担当者の歩行、精密な干渉判定、音響照明への制御送信。
