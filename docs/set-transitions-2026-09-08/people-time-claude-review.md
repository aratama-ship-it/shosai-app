実装や探索は行わず、提示された仕様のみを読み取り限定で検討しました。結論: 骨格は整合していますが、判定を成立させる「同一人リンク」「個人予定の正本」「枠の時刻基準」の3点が未定義のまま2・3・5が依存しており、そこが具体的な矛盾です。

1. 同一人リンクの欠落(①②③全てに波及)。案1は「同じ実際の人を二重登録して暇と見なさない」としつつ、castId/staff温存・人物ID分離・移行規約は後日。すると規約確定まで、台本側出番(castId)と転換側作業(staff)を同一人に束ねる鍵がなく、案2の一人別表は合成できず、案3の「同じ人は排他」も判定不能。二重計上の温床でもある。最小修正: 移行規約とは別に、暫定の手動対応表(castId/staff→人物)を仕様に含め、未リンクは「同一人か未確認」として競合判定保留(暇とも矛盾とも断定しない)と明記。

2. 着替え・待機の正本がない。案2は一人別表を派生専用としつつ、着替え等は台本予定にも転換予定にも属さず入力先が未定義で自己矛盾。最小修正: 転換予定と同格の「個人予定」を正本として一つ定義し、一人別表はそれも参照する。

3. 枠判定の時刻基準が未指定。案2は「基準確認済みのみ秒軸比較」なのに、案3〜5の枠12秒判定がどの基準か書かれていない。既存設計は表示アニメ秒数と稽古予定を分離済みだが、判定入力からアニメ秒数を除外する規則がなく混入し得る。また枠の開始が合図依存(GO待ち)で固定時刻を持たない場合の扱いがない。最小修正: 判定は稽古予定側の同一基準の値のみ使用、アニメ秒数は不使用と明記。合図起点で締切が定まらない枠は案5の「情報不足で判定不可」に落とす。

4. 担当者可用性の前提。案4はB/C/Dが枠中専従である前提を暗黙に置くが、兼務者の出番重複時の規則がない。最小修正: 警告の計算前提に「担当は枠内他予定なし(仮定/確認済みの別)」を必ず表示し、出番重複が既知なら「担当や前提の矛盾」へ分類。

5. 小さな曖昧さ: 余裕0(案5)は予備時間未設定時に警告か通常か未定義。「収まる(余裕0)」表示で警告にしない、と一行固定を推奨。

なお「見積不足≠物理的不可能」の扱い(案4・5の文言)と、未知を0にしない規則は整合しており、そのままで良いです。裏方の名簿縮小懸念は、既存の区間担当・局所待機/交代機構に裏方人物を手動で載せられる、と一文足せば解消します。
