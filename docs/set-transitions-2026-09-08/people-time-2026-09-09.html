人物と転換時間の設計

裏方も舞台図に置ける人物として扱い、
人ごとの予定と、設置に必要な時間を確認できるようにします。

確認済み：担当交代の局所試作は本人確認済み。
今回：裏方・人物別予定・時間不足の警告を設計へ追加。機能の実装は後の段階です。

確認済みの交代試作へ

同じ人物の仕事をまとめる

演者・裏方・兼務を扱います。裏方も作業図に配置でき、袖や待機場所への動線を持てる設計です。名簿への登録だけでは、舞台上へ自動配置しません。

人物の例区分人物別に見る予定の例
A演者・裏方を兼務出番 → 袖へ移動 → 大道具の補助 → 次の出番待ち
B裏方搬入 → 設置 → 固定 → 担当交代
C裏方準備 → 合図待ち → Bと設置作業

架空の予定の例です。台詞や合図の時刻が未定なら、このような順番の表で残し、正確な秒幅へ変換しません。

同じ人が複数の役を演じたり、転換を手伝ったりしても、予定は同じ人物へ集約します。「転換係A」のような担当枠と実際の人物を分け、工程ごとに誰が担当するかを結び付けます。対応が未確認なら、同じ名前だけで統合せず「担当未確定」と残します。

人物別の予定は台本や転換にある作業を参照して表示します。同じ作業が両方に載っていても二重に時間を数えません。着替えなどの独立した作業は「人物の予定」として一度だけ記録し、この表に合わせて表示します。未記入の予定は「空いている」扱いにしません。

転換時間の不足を知らせる

たとえば、同じ裏方B・Cが搬入8秒 → 設置6秒 → 固定4秒を順に行う場合。転換枠が12秒なら、入力した所要では6秒不足します。

ここからは時間の判定を説明する別の架空例です。実測値でも、実際の設置方法の指示でもありません。

狭い画面では図を左右へスクロールできます。締切線は設置の途中を通ります。

例の条件：開始合図を0秒、12秒後を固定完了の締切とします。B・C・Dは開始位置に準備済みで、作業中に他の出番がないと仮定しています。担当の退避は、この例の締切には含めていません。

入力した所要では6秒不足

転換枠12秒 ／ 搬入・設置・固定に18秒。
不足を決める工程と担当を示し、手順や転換枠を見直せるようにします。

別担当Dの10秒作業が並行できるなら、18＋10＝28秒とは計算しません。同じ人の別作業や、前の出番が終わるまで開始できない条件も含めて比較します。

人数を増やせば比例して速くなるとは推定しません。所要を短縮したり、合図や配置を変えたりする判断は人が行います。

不足と未確定を分ける

状況表示すること
入力した所要が長い「6秒不足」＋根拠の工程・担当・開始と締切。
作業は収まるが余裕が少ない残り時間を示す。枠と所要が同じなら「入力上は枠内／余裕0秒」。予備時間未指定なら時間不足の警告にはしません。指定した予備時間の不足は別に示します。
担当・順番に矛盾がある出番との重複、二重割当や互いに待つ工程を示す。勝手に順序付けして、成立した計画へ変えない。
所要や合図の時刻が未定「判定できない」＋未定の箇所。既知の必須工程だけで枠を超える場合は、その範囲に限って不足を示す。

「Q12から12秒以内」なら、その合図を起点に比較できます。「Q12からQ13まで」で間隔が未定なら、枠の秒数は判定できません。画面のアニメーション速度は、作業時間の根拠に使いません。

担当の他の予定が未確認なら、その条件も表示します。所要が枠内というだけで、実際にその人が作業できるとは決めません。

警告の根拠が見積もりなら「入力した所要では」と明示します。稽古での計測値は、予定に採用した値と分けて残します。場所・人数・手順が変わったら、その見積もりを再確認します。

後の実装順序

  1. 人物と時間の基準をそろえる。担当枠・台本の役を実際の人物へ結び付け、個人予定の入力元と時刻の起点を決める。
  2. 人ごとの予定を見せる。出番・移動・着替え・待機・転換・合図の関与を並べる。
  3. 転換枠と比較する。必要所要と開始条件から、不足と未確定を知らせる。

台本キュー側と担当枠・人物の区別を照合し、Claude Code Fableのレビューを受けて、未対応の人物・個人予定の入力元・時間基準・例の条件を具体化しました。

台本の注釈をドラッグして位置を替える操作は、参照の付替えです。人物の予定の実行やGO発火にはしません。
