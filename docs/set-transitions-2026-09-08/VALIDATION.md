## 検査時の修正と限界

- 合図待ち中に「次の手順」を押しても進まない状態は、ボタンを無効にして専用の「合図を確認して次へ」へ統一。
- 合図待ちをOFFにしたとき、手順表側も「机の搬出完了後」へ変わるようにした。
- 最初の検査ではrangeの0.1秒丸めが先に13を表示し、実際の完了前に終点を判定した。検査を「転換完了」状態まで待つ形に改め、端点を確認した。
- design-lintの全ページ測定は初期表示に対して実施。合図待ち・再生・reduced-motionは別の操作確認で検証。全言語・全状態の製品アクセシビリティを証明するものではない。
- 通常サンドボックス内のlocalhost接続/Chromium起動は制限されたため、許可されたサンドボックス外でこの資料だけを検証した。
- 設計用の固定例であり、任意セット追加、経路編集、保存、3D、担当名の入力はまだ製品仕様の提案。デモで実装済みとは扱わない。
