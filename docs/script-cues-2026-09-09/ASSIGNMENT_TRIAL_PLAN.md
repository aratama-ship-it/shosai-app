# 仮台本で割当を一巡する

2026-09-09 / Astra / 局所試作。本人が左右配置に賛成し、制作中の実台本の代わりに適当な素材で進めることを指定。

## 今回の判断

演出・舞台監督が稽古中に、舞台を見ながら台詞へシーン・キューを結ぶ。まず触って分かり、変更を戻せる感覚を確かめる。舞台の平面図、シーンという用語、紙色、左の道具と右の台本を継承する。常設案と押出案の比較は既存資料を残し、本人が賛成した押出式で一巡する。PDFの内容が固まるまで入力を待つ必要はない。

舞台中央を保つ通常表示と、左右を大きくした割当専用表示を比較した。今回は通常表示で始め、狭幅は「項目を選ぶ→台詞を押す」で持ち越す。ドラッグ中に画面幅を変えない。製品メニューのダミー機能を増やさず、シーン1件・照明キュー1件に限定する。

## 仮素材と範囲

- 自作の短い架空台本『扉の向こう』旧版・改訂版、各2頁。台詞追加と頁移動を含む。作品内容への提案や承認済み原稿として扱わない。
- PDFを実際に生成し、Popplerで画像化。PDFから抽出した本文の矩形を局所JSONへ入れる。ブラウザはこの2ファイル専用の画像と矩形を表示する。汎用PDF読込み、OCR、任意単語選択の完成ではない。
- シーン/キューの新規割当、付替え、Undo、明示的舞台表示、モード切替の保持。改訂版へ切替時は既存割当を要付替えとして一覧に残し、元の参照と文言を保持する。付替えは表示位置の確定であり、合図の意味/時間条件の確認ではない。
- 試作のPDF・Q・割当は、同じ端末・同じブラウザのIndexedDBへ自動保存して再読込み時に復元する。これはバックアップ・同期・製品projectへの保存ではない。GO、人物時間計算、転換実装、外部公開は含まない。
- 共通予定・人物・時間は転換側の SHARED_PEOPLE_CUES_TIME_CONTRACT_2026-09-09.md を参照する。本試作から新たな正本や保存形式を追加しない。

## 本人の操作確認後: 未割当警告と道具の位置

2026-09-09。本人は試作を良いと評価し、未割当の警告と、割当道具を平面図/台本の間へ移すことを指定。全体メニューのレールは左に保ち、割当の局所道具だけ台本に隣接させる。新しい主配置は「左レール / 舞台 / 割当道具 / 台本」。以前の左右配置案のうち、割当道具の左常設はこの指定で更新する。

警告は台本に結ぶ対象の全件から計算する。現在頁だけに絞らない。局所fixtureはシーン4・LX 12の2件が対象。割当なし=未割当、別の版や見つからない行への参照=要付替え、現在版の有効な参照=割当済み。合図の意味や時間条件の確認済みとは扱わない。シーン3等、割当対象として登録していない舞台上の情報を勝手に必須扱いしない。

台本ありでは上部に件数の警告と「対象を見る」を表示し、道具一覧の「要対応のみ」へ直接つなぐ。常時ポップアップを出す案は採らず、稽古作業を続けながら残件を把握する。全件を置くと警告を割当件数表示へ変え、Undoで未割当へ戻れば再表示。改訂版では要付替えを再計算する。台本なしでは台本への未割当警告を休止し、戻せば現在の残件を再表示する。データは消さない。
