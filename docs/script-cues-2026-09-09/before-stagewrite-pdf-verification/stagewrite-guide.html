02 / PDFを入れる

最初の台本を読み込む。

  1. 作業するProductionを開く。検証作品は「Stage Sketch migration test 2026-09-09」。PDF表示へ切り替えます。
  2. PDFメニュー → Import New PDF上部の台本取込みアイコンを押します。
  3. 確認を読んで、初回だけYES。既存の作業がある場合は、後述のページ差替えと使い分けます。
  4. 端末のファイル選択でPDFを指定。「Processing PDF」の後に台本が表示されるまで待ちます。今回の日本語PDFは表示できました。

Import New PDFは改訂用の単純な背景交換ではありません。
既存のActions、Light Cues、Texts、Chart associationsを除去すると警告されます。今回実行したのは空の作品への初回取込みだけです。

03 / キューを置く・直す

範囲を選び、余白にQを書く。

  1. 上部のQsを押す。キュー追加モードを有効にします。もう一度押すと解除するトグルです。
  2. 紙面で対象範囲をドラッグ。クリックだけではなく、始点から終点へ範囲を作ります。
  3. LeftまたはRightを選ぶ。台本のどちら側にキューを置くか決めます。検証ではRightを使用しました。
  4. キューの文字を入力して保存。例は「LX 12 · 扉を開ける」。上部の保存アイコンで保存します。

後からの修正は、キューを選択して行う。

内容を直す
キュー文字をクリックして編集します。今回、日本語を含む番号・説明の入力と保存を確認しました。

位置を直す
範囲枠とキュー文字枠のハンドルを別々にドラッグします。今回の付け直しでは両方を対象の台詞の高さへ移し、保存しました。

Box / Marker、Bottom / Topや装飾ツールは画面上の存在を記録したものです。全設定の挙動は検証していません。

04 / 台本を改訂する

「新規取込み」と「ページ差替え」を使い分ける。

Import New PDF

既存キューなどを除去する警告。
最初の台本を入れる入口です。既存の作業がある場合、内容を読まずにYESを押さないようにします。

表示中の1頁を、選んだPDFの先頭頁で差し替えます。今回、キュー1件が残ることを確認しました。

枠と文字をドラッグして保存。

  1. 差し替えるページを表示する。Replace Current Pageの対象は現在の1頁です。
  2. PDFメニュー → Replace Current Page → YES。ファイル選択で改訂PDFを指定します。今回の2頁PDFでも使われたのは先頭頁だけです。
  3. 残ったキューと台詞を照合する。キューの保持と、正しい位置への追従は別です。今回の台詞移動では位置は追従しませんでした。
  4. 必要な枠と文字を移動して保存する。ページをまたぐ付け直しや複数頁一括改訂の操作は、まだ確認していません。

舞台スケッチで重視する点
旧版とキューを残し、改訂後に位置確認が必要な項目を知らせる。前の位置を見返しながら、付け直しを進められるUIにつなげます。

05 / PDFを書き出す

生成したPDFは、Recent PDFsから探す。

  1. 右上の出力アイコン → Production - PDF。台本を対象にする選択肢です。Charts付きの出力は今回試していません。
  2. Printing Options → PRINT PDF。検証ではPrint chart-script linksをNOのまま使用しました。
  3. Recent PDFsに履歴が出るのを確認。今回の出力では日時付きの項目とダウンロードアイコンが表示されました。
  4. 履歴右端のダウンロードアイコン。項目名を押す操作とは分かれています。実ファイルを取得できたら、注釈・日本語・頁数を確認します。

ここは検証が残っています。
内蔵ブラウザでアイコンを押しましたが、ファイルを取得できませんでした。生成履歴は確認済み、出力内容と舞台スケッチへの再読込みは未確認です。原因や一般利用時の成否は断定していません。

撮影条件・資料の扱い

撮影対象は検証作品「Stage Sketch migration test 2026-09-09」。使用PDFは架空の「扉の向こう」旧版・改訂版です。8枚の実画面は加工せず保存し、説明用の番号だけHTML上に重ねています。

これは個人用の参照資料で、Stage Write公式マニュアルではありません。画面内の商標・UIは各権利者に帰属します。資料と画像は同じフォルダ構成で保管するとオフラインでも参照できます。
