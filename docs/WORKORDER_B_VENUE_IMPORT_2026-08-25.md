## 背景（なぜ直すか）

リリース前レビュー P1-8。**取り込みが、利用者の確認を待たずに会場ライブラリを書き換える。**

`stage-venue-editor.js` の `importLibraryFile()`（1610行付近）は、ファイルを読んだら
そのまま `library.importVenues(venues)` を呼び、**その場で端末の会場ライブラリへ書き込む**。
プレビューも確認もない。取り消す手段もない。

検証もほとんどしていない。現状あるのは次だけ:

- JSONとして解析できるか
- 配列、または `kind === "shosai-stage-venue-library" && version === 1` か

**足りていないもの**: 各会場の形（`kind`・スキーマ）、ファイルサイズの上限、
件数の上限、切り捨てが起きたことの通知。

舞台スケッチは配る製品なので、**他人から受け取ったファイルを開く場面**が本番になる。
壊れたファイルや巨大なファイルで、利用者の会場ライブラリが壊れてはいけない。

## やること

### B-1. 取り込みを二段階にする（読む → 見せる → 確定）

`importLibraryFile()` を、**確定するまで `library` へ一切書き込まない**形へ変える。

1. ファイルを読み、検証する（B-2）
2. **プレビューを出す**。取り込む会場の一覧（名前・間口・奥行・高さ・出所）と、
   「取り込む」「やめる」の2つを見せる
3. 「取り込む」を押したときだけ `library.importVenues()` を呼ぶ
4. 「やめる」を押したら**何も残さない**

**★「やめる」で何も残らないことが、この課題の核。** 現状はここが壊れている。

プレビューの置き場所は、既存の窓（`stage-modal`）の作法に従う。
`index.html` の `stage-venue-editor-modal` の近くに置き、`stage-sketch.js` の
`openReachTable()` / `closeReachTable()`（2026-08-25 に追加）と同じ形で開閉する。
**暗幕クリックとEscapeでも閉じられること。閉じたら取り込まない。**

### B-2. 検証を足す

取り込む前に、次を順に見る。**一つでも外れたら取り込まず、理由を利用者へ見せる。**

| 検査 | 上限・条件 | 外れたときの文言（例） |
|---|---|---|
| ファイルサイズ | **2MBまで** | 「このファイルは大きすぎます（○MB）。会場ライブラリは2MBまでです。」 |
| 全体の形 | 配列 or `kind === "shosai-stage-venue-library"` かつ `version === 1` | 「会場ライブラリの形式ではありません。」（現状の文言を流用） |
| 件数 | **200件まで**。超えたら**先頭200件だけ取り込み、切り捨てた件数を必ず伝える** | 「○件のうち200件を取り込みました。残り○件は取り込んでいません。」 |
| 各会場の形 | `venue-v2` として妥当か（下記） | 「取り込めない会場が○件ありました。」 |

**各会場の妥当性**は、既存の作りに合わせること。**まず `stage-venues.js` に
検証の仕組みがあるか調べ、あればそれを使う**（`importVenues` の中で弾いている可能性が高い。
二重に書かない）。無ければ最低限、次を見る:

- オブジェクトであること
- `id` と `label` が文字列で、空でないこと
- 寸法（間口・奥行・高さ）が有限の数で、正であること

**★「取り込めた件数」だけでなく「取り込めなかった件数」も必ず表示する。**
黙って減るのが最も困る。

## 共通の制約（必ず守る）

- **既存ファイルは編集前に必ず読み直す。** 他のエージェントや別PCが同じファイルを触っている前提。
- **ファイルの削除・移動はしない。**
- **版上げ（`?v=`・`CACHE_NAME`）と `build_stage.py` の実行はしない。** 発注元がやる。
  ただし `index.html` を触ったら「触った」と報告すること（発注元が再生成する）。
- `stage.html` を直接編集しない（生成物）。
- 日本語UI文字列を足したら、**`stage-i18n.js` へ英語も登録する**。
  `tests/stage-i18n-coverage.test.mjs` が未登録を検出して落ちる（2026-08-25 に実際に踏んだ）。
- 既存テストを壊さない。落ちる場合は**そのテストが何を守っていたのかを報告する**（勝手に消さない）。
