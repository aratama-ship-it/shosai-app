# 発注書：小道具の見取り（誰が何を持っているか＋受け渡し）2026-08-20

Claudeが仕様を決め、Codexが実装し、Claudeが検証する。この文書だけで着手できるように書く。
前提: 持ち物機能・形プリセット・一覧グループ分けは実装済み（現在 stage-sketch v260・CACHE v91）。

## 背景（本人が承認した提案・2026-08-20）

シーンごとに「誰が何を持っているか」を出し、**転換時の小道具の受け渡し管理**に使えるようにする。
劇場の小道具帳（プロップス・プロット）に相当するものを、この道具の流儀で。

## 出す場所は2つ

1. **画面内**: シーンの説明（textarea）のすぐ下に、**前のシーンから小道具の動きがあるときだけ**
   一行出す（読み取り専用の `<p>`。動きが無ければ出さない＝散らかさない）。
2. **印刷用ページ**（`openPrintPage`・stage-sketch.js ~13542行）:
   - 各シーンの meta に「小道具」の行（いま誰が持っているか・床の物はどこか）
   - 各シーンの meta に「受け渡し」の行（前のシーンとの差分）
   - 末尾に**小道具の香盤表**（行=小道具、列=シーン、セル=持ち手）を一枚
   香盤表は機能スイッチ `propsplot`（FEATURES に追加、`def: true`、
   label「小道具の香盤表（印刷）」、hint「印刷用ページに、シーンごとの持ち手と受け渡しの表を足す」）。
   各シーンの「小道具」「受け渡し」行は同じスイッチに連動させる。

## 差分の取り方（識別）

- 小道具＝ `kind === "prop"` の登録（`state.project.sets`）。**同一性は `setId`**（シーンをまたいで安定）。
- 登録の無い prop 駒（AI JSON等）は今回対象外（無視してよい。落ちないことだけ保証）。
- 持ち手＝ `piece.heldBy` の指す演者駒。表示名は名簿（castId→名簿名）、無ければ pieceLabel。
- シーン列は `state.project.scenes` の `kind === "scene"` を順に。前のシーンとは**直前の scene 行**
  （section を飛ばす）。
- 状態は3値: **持たれている（誰・どちらの手）／床（舞台上・持たれていない）／出ていない**
  （そのシーンに駒が無い、または舞台エリア外）。舞台上判定は既存 `onStageArea(u, v)` を使う。

## 文言（この形をそのまま使う）

**シーン内の「小道具」行**（印刷 meta）:
`小道具: 傘=A乙骨役（左） / ランタン=F夏油役（右） / 帽子=床・中央`
- 持たれている: `名前=持ち手名（左/右）`
- 床: `名前=床・上手／中央／下手`（u<0.4=下手、u>0.6=上手、それ以外=中央。
  ※このアプリの座標は u が大きいほど上手側。既存の bamiri の SL/SR 換算に合わせて確認する）
- 英語: `Props: Umbrella=A (L) / Lantern=F (R) / Top hat=floor DS-centre` 相当の素直な形でよい

**「受け渡し」行**（印刷 meta・画面内の一行も同じ整形）:
- 持ち手交代: `傘: A → B`
- 置く: `傘: Aが置く`
- 取る: `傘: Bが取る`
- 持って登場: `傘: Bが持って登場`
- 床へ登場: `傘: 床へ登場`
- はける: `傘: はける`
複数は ` ／ ` で繋ぐ。画面内の行は先頭に `小道具:` を付ける。
英語: `Umbrella: A → B` / `A sets it down` / `B picks it up` / `B enters with it` /
`enters (on floor)` / `cleared`。

**香盤表**（印刷末尾・cuesheet と同じ体裁の table）:
- 見出し行: 小道具名（左端）＋シーン番号
- セル: 持ち手の短い名前（名簿名を8文字まで）／`床`／出ていなければ空
- 前のシーンから状態が変わったセルに `class="changed"`（cues の既存スタイルに合わせ、
  太字か下線などささやかな強調。派手にしない）
- 表題: `小道具の香盤表` ／ en: `Props plot`
- 小道具が1つも登録されていなければ表ごと出さない

## 画面内の一行（実装位置）

シーンの説明 textarea（プレースホルダ「この場面で何が起きるか」）の直下に
`<p id="stage-prop-moves" class="stage-prop-moves" hidden>` を追加。
シーン切替・持ち物変更・undo 等の後（renderScenes か updateInspector と同じ再描画経路）で更新する。
動きが無ければ `hidden`。スタイルは既存の補足文（.stage-cast-hint 等）に合わせた控えめな一行。
機能スイッチには連動させない（動きがあるときだけ出るので常設でよい）。

## 制約（必ず守る）
