## やること（この6箇所の数値だけ差し替える）

### 1. `TORSO_RINGS`（1607行あたり）

```js
  const TORSO_RINGS = [
    { t: 0.00, halfX: 0.116, rz: 0.053 },    // 肩
    { t: 0.14, halfX: 0.100, rz: 0.063 },    // 肩の下
    { t: 0.30, halfX: 0.090, rz: 0.061 },    // 胸
    { t: 0.62, halfX: 0.076, rz: 0.052 },    // くびれ
    { t: 0.90, halfX: 0.088, rz: 0.065 },    // 腰（骨盤の張り）
    { t: 1.16, halfX: 0.062, rz: 0.047 },    // 股
  ];
```

既存のコメント（凸包を使うな・肩幅を肩関節に合わせる理由・くびれの理由）は**そのまま残す**。
そのうえで、各行の末尾コメントは現状の部位名を維持しつつ、必要なら実測値である旨を足してよい。

- `halfX` の t=0（肩）0.116 は**据え置き**。実測の肩まわりの外形半幅は 0.1217 で、
  ここを細くすると腕の付け根の丸が胴の外へ飛び出す（既存コメントの警告どおり）。
- `t: 1.16` の halfX 0.062 も**据え置き**。実測では股の断面は 0.017 しかないが、
  それは左右の腿に分かれた谷であって、ここを絞ると腿の付け根が胴から切り離される。
  作図都合の値として維持する。

### 2. `NECK_RINGS`（1626行あたり）

```js
  const NECK_RINGS = [
    { s: 0.18, halfX: 0.086, rz: 0.048 },   // 僧帽筋
    { s: 0.55, halfX: 0.040, rz: 0.038 },   // 首
    { s: 0.85, halfX: 0.034, rz: 0.046 },   // 頭の中まで差し込む
  ];
```

s=0.85 の rz を厚くするのは、実測で頭は**左右幅より前後の奥行きが大きい**（半幅0.049 に対し
半奥行き0.050〜0.058）ため。後頭部のぶんが今は足りていない。

### 3. `LIMB_TAPER`（1634行あたり）

```js
  const LIMB_TAPER = {
    // 腿の付け根 → 腿の中 → 膝 → ふくらはぎ → 足首
    leg: [0.056, 0.058, 0.034, 0.039, 0.021],
    // 肩 → 上腕の中 → 肘 → 前腕の太い所 → 手首
    arm: [0.029, 0.029, 0.027, 0.021, 0.0135],
  };
```

- 腕の「肩」0.029 は**据え置き**。実測の 0.036 は三角筋の張り出しを含むが、
  ここは肩関節（x=±0.115）の真上なので、太くすると肩幅が実測の 0.24H を超えて角張る。
  三角筋の塊は `TORSO_RINGS` の t=0 が受け持つ。
- 腿だけが大きく太る（0.047→0.058）。**ここが今回の主眼。**

### 4. 手・足の寸法（1642〜1645行あたり）

```js
  const HAND_LEN = 0.062;      // 手首から指先まで
  const HAND_R = 0.019;
  const FOOT_R = 0.021;        // 足の甲の厚み
  const HEEL_BACK = 0.030;     // 踵がくるぶしより後ろへ出る量
```

`HEEL_BACK` は実測（くるぶしの z=+0.013、踵の後端 z=−0.017）から 0.030。
`HAND_LEN` は実測の手の長さ 0.087 に対して控えめに 0.062（舞台スケッチは
手のひらの塊として描く方針のため、指先まで伸ばさない）。
