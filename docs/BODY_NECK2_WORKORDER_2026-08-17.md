## 前便で直らなかった理由（幾何で確認済み）

第3便では首の最細部を halfX 0.037（幅12.2cm・165cm換算）にした。しかし
**第2便のスタイル調整で頭の横半径を 0.046→0.0445（幅14.7cm）に細くしていた**ため、
首と頭の差がわずか17%しかない。さらに頭は楕円なので**下端が尖っており、顎の高さでは
ほぼ幅ゼロ**になる。その空白を首の輪郭（0.037）が埋めるので、
**肩から頭までが一本のなだらかな円錐**になっていた。

数値で言うと、頭の楕円（縦半径0.065・横半径0.0445・中心 y=0.935）の横幅は

| y | 頭の半幅 | 首の半幅（第3便） | どちらが外側か |
|---|---|---|---|
| 0.875 | 0.013 | 0.036 | **首**（頭が首に埋もれる） |
| 0.885 | 0.028 | 0.036 | **首** |
| 0.895 | 0.036 | 0.035 | ほぼ同じ |

つまり**顎から下の全域で首のほうが太い**。首が見えるはずがない。

## 直し方（2つ同時に効かせる）

1. **首を細くする** 0.037 → **0.031**（幅10.2cm。実測は12.4cmだが、正面の輪郭では
   顎の下に隠れる分があるので、シルエットとしてはここまで細くてよい）
2. **頭の幅を実測へ戻す** 0.0445 → **0.048**（幅15.8cm。実測の頭幅は約15cm）。
   **縦半径 0.065 は変えない**ので、7.7頭身というスタイル調整は保たれる。
   細くしていたのは横幅だけで、そこが首との対比を消していた。

この2つで首と頭の差が 17% → **35%** になり、y=0.864〜0.885 に
**半幅0.031の首の柱が約3.5cm分、頭の下に現れる**。

あわせて僧帽筋の傾きを実際の角度に合わせる。肩関節（y=0.82・半幅0.102）から
首の付け根（y=0.845・半幅0.048）までは、実際には**水平から約25°**で下る。

### 1. `NECK_RINGS`（1632行あたり）

```js

    { s: 0.09, halfX: 0.082, rz: 0.044 },   // 僧帽筋の峰。ここを飛ばすと肩が角になる

    { s: 0.55, halfX: 0.031, rz: 0.033 },   // 首の柱。★ここが実際に目に見える首

```

直前のコメントのうち、第3便で足した2行

```

   *   枚数を増やして首を作る。s=0.40 が実際に見える首の最細部。
```

を、次の3行に**差し替える**（それ以外の既存コメントは残す）。

```
   * ★首が出ない原因は枚数ではなく、頭の楕円との太さの差だった（2026-08-16→17に2回踏んだ）。
   *   頭は下端が尖るので顎の高さでは幅がほぼ0になり、そこを首の輪郭が埋めて円錐になる。
   *   首(0.031)を頭の横半径(0.048)より35%細くして、初めて首の柱が見える。両方を一緒に見ること。
```
