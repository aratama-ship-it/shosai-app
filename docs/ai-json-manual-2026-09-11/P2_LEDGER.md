# P2 通し試験 台帳（外部AI × 課題）— テンプレート 2026-09-11

目的: マニュアル v0.2.0 を「そのAIに貼るだけ」で、舞台スケッチに読み込めて意味が保たれるJSONが出るかを測る。
記録は「開けた率」と「意味が保たれた率」を分ける。1本ごとに1行。

## 手順（1本あたり 5〜10分）
1. 新しいチャットを開く（履歴なし）。`docs/ai-json-manual/AI_MANUAL_ja.md` の全文を貼る。
2. 続けて下の課題文を貼る。**課題1は情報を意図的に欠く**（質問票が出るかを見る）。課題2は全部指定する。
3. 質問票が出たら台帳に記録し、「Q1 B、Q2 保留、Q3 A」のように答える。
4. 返ってきたJSONを `docs/ai-json-manual-2026-09-11/p2-runs/<AI>-<課題>-<回>.json` に保存。
5. `node tools/ai-json-check.mjs <file>` の結果を記録。NGなら**そのNG本文をAIに貼って**修正版をもらう（修正回数を数える）。
6. 舞台スケッチ（体験版または本番）の「読み込む」→ 比較画面 → 「別のショーとして開く」。全場面を正面図・平面図で見る。
7. 意味の照合: 人数・場面数と順序・section階層・題名・note・姿勢・色・位置の粗い意図・照明の有無 が課題と回答どおりか。

### 本番P2 完走 6/6（2026-09-11・ChatGPT 2本＋Claude.ai 2本＋Gemini 2本）
- 開けた率: 6/6（NG版も開けてしまう）。意味が保たれた率: 初回 4/6（ChatGPT課題1・Gemini課題1が NG）、修正後 6/6（いずれも NG本文を1回貼るだけで直った）。質問票が出た率: 3/3（課題1のみ質問票を伴う）、妥当だった率: 3/3。
- 黙った変形の実例が2種: ①参照切れ（ChatGPT）→別人物として描かれる ②色の書式ミス（Gemini・先頭空白）→全員が既定色に化ける。どちらも検査器なら1発、ブラウザは無警告。
- 頼んでいない lightingIntent の追加: v0.2.2（禁止行あり）では Claude.ai・Gemini とも 0件（ChatGPT の2本は v0.2.1 で発生）。禁止行は効いている。
- **P4判断の材料**: 5本中2本が初回に「黙った変形」を含んでいた（40%）。検査器を使えない一般ユーザーには、読み込み時の点検表示（参照切れ・色書式・未知キー・規模の不一致の4点だけでも）か端末内チェッカーが必要と判断できる材料が揃った。→ 判断用HTMLを次に作る。
- 操作上の注意（自動操作の記録）: Claude.ai は Enter で送信されるため複数行の貼り付けは execCommand('insertText') で一括投入する／同一タブでの「新規シークレットチャット」は前会話が残ることがある（タブを閉じて開き直す）／Gemini は Enter で送信されず送信ボタンを押す。

判定の言葉: 読み込み＝「開けた／止まった（理由）」、意味保持＝「保たれた／一部欠落（何が）／別物」。
集計は「開けた率」「意味が保たれた率」「質問票が妥当だった率」の3つを分けて書く。
再現する欠落（2本以上で同じ）は本文の修正対象。文書で防げない「黙った変形」が1件でも出たら P4（読み込み時の点検表示）を検討する。
