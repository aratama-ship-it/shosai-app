# 舞台スケッチ 音楽編集・設計確認用トークン

## 本体実装（本人承認・2026-09-12）

現行の舞台編集画面を共有したまま、上部の2タブで `通常モード` / `タイムラインモード` を切り替える。
二つのモードは別レイアウトを持たず、同じパネルDOMと保存済みの左右位置・順番・開閉状態を使う。
したがって、どちらのモードでパネルを並べ替えても、もう一方へそのまま継承される。

タブは既存ヘッダー内で「舞台スケッチ v0.3.6 β版」の右隣へ置き、専用の一段を持たない。
タイトルとの間隔16px、操作高44px、タブ間隔4px、角丸4px、選択中は `--nm-accent` の下線2pxと
太字で現在地を示す。狭い幅ではタイトル行の中だけで折り返し、保存注意と右上操作の構造は変えない。
右上の全画面操作は文字を併記せず、周囲のアイコン操作と同じ44px角・SVG 20pxで揃える。
意味は `aria-label` と `title` に残し、キーボード操作の案内も維持する。
タイムラインモードだけ下部のタイムラインを表示する。作図面は正面／平面／両方①／両方②を残し、
タイムラインモードを初めて開いたときだけ平面を既定にする。通常モードへ戻したときは、通常モードで
最後に使った一図／両図と上下順を復元する。モード・時間/カウント・ズーム・各モードの図選択は端末表示設定として保存し、
ショーのシーン・配置・パネルレイアウトの正本へは混ぜない。

パネル表示は編集モードごとに端末設定を持つ。通常モードは2列、タイムラインモードは1列を初期値とし、
環境設定の「パネルの表示スタイル」で各モードを1列／2列へ切り替えられる。今後モードを追加するときも、
モードタブの定義から同じ設定行を生成し、固定のモード名を設定画面へ重複記述しない。

### ミュージックシンク操作列と可変高（本人指定・2026-09-13）

- 操作列: ミュージックシンクで現在表示されている上段と下段の操作を、タイムライン上部へ2列で並べる。音源・保存など舞台スケッチに同じ入口があるものは既存操作へ接続し、まだ本体側に編集処理がないメトロノーム・頭合わせ・BPM推定・分割・記録は、配置と名称を先に確定できる無効状態で置く。ミュージックシンク側で非表示の「音の確認」「複製」「削除」は並べない。
- 操作高: 各ボタンと入力の最小高44px、列間4px、左右余白8px。横幅に収まらない場合は操作列の中で折り返し、画面外へ隠れる操作を作らない。折り返しで狭くなったタイムラインは上端ドラッグで広げられる。
- パネル高: 初期360px、最小260px、最大は画面高の72%または上側160pxを残す高さの小さい方。上端の12px幅の水平セパレーターを上へドラッグすると高く、下へドラッグすると低くなる。上下キーは24px刻み、ダブルクリックは360pxへ戻す。高さは端末表示設定として保存する。
- 拡大縮小: ミュージックシンクと同じく0.15〜12倍、1操作1.3倍。`−`／`＋`ボタン、`Cmd（Ctrl）+ホイール`、文字入力中を除く`＋`／`−`キーを用意する。ホイール操作ではポインタ下、ボタン・キーでは表示中央の時刻を動かさずに伸縮し、倍率は端末へ保存する。レンジ入力は置かない。
- 再生操作: 操作順は `先頭` → `前` → `再生` → `次`。この4操作、メトロノーム、楽曲削除は44px角のアイコンだけで示し、名称は `aria-label` と `title` に残す。分割操作の表示名は `シーン分割` とする。
- 配色操作: タイムライン内部には明暗切替を置かない。配色は舞台スケッチ本体の環境設定に一本化する。

## 承認前の設計確認案（履歴）

旧案のタブ・専用カラムは不採用。現行の舞台編集UIをそのまま表示し、追加は下部タイムラインのみ。既存の図選択プルダウンから両方表示を除き、一図表示にする。
新CSSは timeline-only.css。既存ヘッダー・カラム幅・道具配置・舞台描画には上書きなし。タイムラインだけ高さ248px、既存画面は残りの高さをスクロールして使う。行高:操作52/目盛28/波形40/シーン48/転換48/注記32px。文字12/14px、行間1.6、余白8/12px、操作44px、背景#29231e・文字#efe7d6・補助#cbbba4・選択#d3ac59（下記実測を再利用）。狭い幅はタイムライン内だけ横スクロール。
以下の旧案の寸法・監査記録は履歴であり、現行画面の合格根拠ではない。現在の確認記録はtimeline-check.json。
現行の実描画: 既存ヘッダー・左右列・中央バー・平面canvasのx座標/幅/書体を追加CSS有無で比較し一致。一図切替・タイムライン単位・シーン選択も確認。全画面design-lintは既存の小型操作子・行送り・スクロール領域等を含めNG199/WARN0（timeline-audit/report.md）。既存UIを変えない指示のため、それらは今回修正せず、全画面合格とは報告しない。追加タイムラインに名指しされた指摘はなし。
