DESKTOP BUILD

Mac版を入れる

ブラウザ版と中身は同じです。同じファイルを読む「窓」が一つ増えるだけで、 ショーの保存先も設定も共有されます。Mac版でだけできることが二つあります。

ブラウザ版との違い

  • AIに直させる——舞台スケッチのAI指示は、Mac版の中だけで動きます。 ブラウザではこの項目自体が現れません。
  • 書き出し先を選べる——保存ダイアログでフォルダを指定できます。

それ以外の機能に差はありません。ブラウザ版で足りているなら、入れる必要はありません。

受け取る

制作の書斎.app を受け取る

zip 約1.7MB ／ Apple Silicon (arm64) ／ macOS 13 以降

Intel Macでは動きません。arm64だけの造りです。

入れかた

  1. zipを開くと 制作の書斎.app が出ます。
  2. 「アプリケーション」フォルダへ移します。
  3. 最初の一回だけ、アイコンを右クリック（control＋クリック）して 「開く」を選びます。出てくる確認でもう一度「開く」。

ふつうにダブルクリックすると「開発元を確認できないため開けません」と 止められます。Appleへの登録（署名・公証）をしていない手元の造りだからです。 右クリックからの「開く」は一度通せば覚えます。次からはダブルクリックで開きます。

★動かすには作業フォルダが要る

このアプリは中身を抱えていません。iCloud上の shosai-app フォルダを そのまま読む窓です。だからブラウザ版を直せばMac版にも同時に届きます。 裏返すと、そのフォルダが無い Mac では起動しません。

既定で見に行く場所はこれです。

/Users/arata/Library/Mobile Documents/com~apple~CloudDocs/claude code files/show-creative-ideas/shosai-app

別のMac（利用者名が違う）へ入れるときは、この場所が変わります。 アプリを一度終了してから、ターミナルで置き場所を教えてください。 

defaults write local.shosai.desk WebRootPath -string "/Users/<利用者名>/Library/Mobile Documents/com~apple~CloudDocs/claude code files/show-creative-ideas/shosai-app"

iCloudの同期が終わっていないと、フォルダはあっても中身が降りてきていないことがあります。 Finderでそのフォルダを開き、雲のマークが消えてから起動してください。

更新する

ふだんの更新に、入れ直しは要りません。画面と機能はフォルダ側にあるので、 ブラウザ版が新しくなればMac版も新しくなります。 入れ直しが要るのは、アプリの殻そのもの（Swift側）を作り直したときだけです。
