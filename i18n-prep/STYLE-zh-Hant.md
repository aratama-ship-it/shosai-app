# 繁体字中国語（台湾正体）スタイルガイド（舞台スケッチUI）

作成: 2026-08-28。`stage-i18n.zh-Hant.draft.js` の訳はすべて本書の決定に従う。
対象は**台湾**の用法。香港は UI 語彙が近い一方で劇場語彙が大陸寄りのため、今回は台湾に統一。

## 1. 声と文体

- 簡潔な書面語。ボタンは動詞句（匯出／復原／重新命名）。案内文は「請…」を文頭にだけ。
- **台湾の劇場現場語を使う**（GLOSSARY準拠）: 左舞台／右舞台（俳優視点）／上舞台（奥）／
  下舞台（手前）／翼幕／沿幕／大幕／天幕／走位／站位／暗場／換場／Cue。
- **「上舞台」を動詞に使わない**（GLOSSARY罠7）。「舞台へ出す」は「放上舞台」、
  upstage の意味の時だけ名詞「上舞台」。
- 大陸簡体字からの機械変換で作らない。UI動詞・IT語彙・劇場語彙の3系統すべてが別物
  （儲存/匯出/設定/載入/影片/音訊/網路/連線/檔案…）。

## 2. 約物・組版

- 句読点は全角: ，。：；！？（）、。**引用は「」（二重は『』）**——大陸の“ ”と逆なので注意。
  UI要素名の引用も「匯出」の形。
- 中西混植・数値・記号は簡体版と同方針（スペースなし、半角数字、8–12、0.6秒）。

## 4. 文の型（SAYテンプレ）

- 完了報告は「已+動詞」: 「已刪除「$1」。」「已匯出 $1 張圖。」
- 依頼は「請先…，再…」。エラーは「無法…。請…」。
- 名前の挿入は「$1」と鉤括弧で包む（数値は包まない）。

## 5. フォント・表示

- Apple: PingFang TC、Windows: Microsoft JhengHei、その他: Noto Sans CJK TC。
  `:lang(zh-Hant)` で分岐。**簡体字フォントで繁体字を出さない**（骨・草冠・辶の字形が別）。
