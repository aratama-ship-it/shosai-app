# 舞台スケッチ — パネル別ON/OFF一覧

- 作成: 2026-09-13 / Codex
- 対象: PC版ヘッダーの環境設定ボタン横と、左右列に存在する全パネルの表示設定。
- 目的: 環境設定を開かず、ヘッダーのボタンから「ショー」「出るもの」「照明」「シーン」「選んだもの」を含む全パネルを個別に表示・非表示へ切り替える。

## 継承する値

| 要素 | 値 | 出所 |
|---|---:|---|
| ボタン高 | 44px | `.stage-history-actions` |
| ボタン幅 | 44px | 共通ヘッダー高と同寸の正方形 |
| アイコン | 22px | 設定・パネル設定のSVG |
| ボタン間隔 | 6px | `.stage-history-actions` |
| 境界線・文字・選択色 | 既存の `--line-dark` / `--milk-dim` / `--brass` | `.stage-lang` |
| 一覧幅 | 260px | `.stage-timeline-settings-panel` |
| 一覧オフセット | 8px | ヘッダー操作との分離 |
| 一覧項目高 | 44px | タップ対象の既存基準 |
| 一覧内側余白 | 左右12px | `.stage-timeline-settings-panel` を小型化 |
| 一覧最大高 | `calc(100vh - 120px)` | 低い画面では一覧内をスクロール |
| モーション | 追加なし | 表示状態は即時切替 |

## 状態と操作

- 並び順は、環境設定 → パネル別ON/OFF → 全画面。
- ボタンを押すと、その画面に実在するパネルのチェック一覧を開き、`aria-expanded` で開閉状態を示す。通常ブラウザは9種類、Mac版は「AI指示」を加えた10種類。
- チェックを変えた瞬間に対象パネルだけを表示・非表示へ切り替え、環境設定と同じ端末設定へ保存する。
- 一覧の外側を押すか Esc で閉じる。Esc では入口ボタンへフォーカスを戻す。
- パネルの左右位置・順番・開閉・表示スタイルは変更しない。
- iPad PWA・スマホ閲覧・ゲスト表示は既存のドロワー／共有導線を守るため対象外。

## 右上アイコンの形状調整（2026-09-13）

- 設定とパネル設定は、共通高44pxに対して幅だけ34pxだったため、実寸が34×44pxの縦長になっていた。
- 両方を44×44pxへそろえ、SVGを19pxから22pxへ拡大する。
- 配置順、6pxの間隔、境界色、ホバー・展開状態、メニューの位置と動作は変更しない。
