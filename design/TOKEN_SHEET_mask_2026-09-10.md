# 舞台スケッチ — 仮面の保持と装着

本人指定: 小道具にマスク（仮面）を追加。左右の手で持つほか、演者の顔にもつけられる。
既存の小道具登録・演者の持ち物欄を使い、顔への装着を独立した1枠にする。

| 項目 | 値 / 方針 |
|---|---|
| 初期寸法 | 幅18cm × 奥行き8cm × 高さ24cm。配置用の初期値で、調整可能 |
| 外観 | 楕円の仮面、目2個と口・鼻。登録色を使用、初期色は既存の紙色 #efe7d6 |
| 顔への装着 | 頭・首・顔の向きから直交基底を作り、頭中心から顔の前へ身長の4.9%進める |
| 手の握り | 中央下部（下端から3.5cm） |
| UI | 既存selectとbtn-quiet。追加ボタンの高さ44px以上。顔への切替は仮面のみ |
| 状態 | heldByは演者参照、holdSideは既存L/R、holdModeはhand/face。旧データはhand |
| 上限 | 演者1人につき右手1個・左手1個・仮面1個。顔は両手の空きに影響しない |
| 解除 | 顔→手は手の空きを検査。空きがなければ装着状態を保持。外すと床へ戻す |
| 保存 | シーン単位。保存・読み込み・複製・Undo・香盤表に装着状態を反映 |
| 動き・依存 | 新規モーション・外部依存なし |

2D・3Dは仮面の描画と顔の座標計算を共用し、背面からは頭の奥へ隠す。
