# 環境設定：説明の折りたたみ（2026-09-11）

## 目的と範囲

環境設定の「パネルのオン／オフ」「機能のオン／オフ」は、初見でも設定名を一覧でき、理由や効き方は必要な項目だけ確認できる密度にする。設定値、表示対象、準備中項目を非表示にする既存方針は変えない。

## 操作

- 各行と「パネルのオン／オフ」見出しの右に、36px角の `？` を置く。
- 説明は `？` をクリックした時だけ表示する。再クリックまたは Esc で閉じる。ホバー／キーボードのフォーカスでは説明を表示しない。
- `？` はチェックボックスのラベル外に置く。説明を確認する操作でオン／オフが変わらないことを優先する。
- `aria-expanded`、`aria-controls`、説明要素の `aria-hidden` を同期し、アイコンの操作目的は項目名と「説明」で読めるようにする。

## トークン

| 要素 | 値 | 理由 |
|---|---:|---|
| `？` 操作面 | 36 × 36px、1px輪郭 | コンパクトさを保ちつつ、設定行内で独立した操作と分かる大きさ。 |
| 行内の間隔 | 8px / 10px | チェック、名称、説明入口を三つの役割として分ける。 |
| 説明文字 | 12px / line-height 1.55 | 通常の設定名（14px）より一段下げ、開いた時だけ読む補助情報にする。 |
| 開閉 | 160ms ease-out、`prefers-reduced-motion` で無効 | 開閉の位置関係は分かるが、作図中の注意を引き続けない。 |
| 説明色 | `--paper` #efe7d6 | `--desk` #191512 上で既存実測 13.88:1。隠すのは量であって読めなさではない。 |
| 操作の輪郭 | `rgba(211,172,89,.42)` → `--brass` #9c823f | 既存の真鍮系の細い罫線と同じ階層。新しい警告色や塗り面を足さない。 |

## 確認条件

- 通常時、各設定はチェックボックス・名称・`？` の一行で見渡せる。
- 説明確認で設定値が変わらない。
- `？` を一度押すと説明が開き、同じ `？` をもう一度押すと閉じる。ポインターを離しても状態は変わらない。
- 日本語・英語・中国語で説明が横幅を越えず、760px未満では既存の一列グリッドへ戻る。
