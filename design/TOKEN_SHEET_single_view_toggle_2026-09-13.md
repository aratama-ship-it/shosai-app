# 1枚表示の正面・平面切り替え

## 対象

- 正面図だけ、または平面図だけを表示している編集画面。
- 両方表示、スマホ閲覧画面、読み取り専用スタディでは表示しない。

## 見た目

| 要素 | 値 |
| --- | --- |
| 位置 | 表示中の図パネルの右12px・下12px |
| 構成 | 正面／平面の2分割ボタン |
| ボタン | 最小52×36px、iPadは高さ44px |
| 選択 | `--rust` の枠と背景、`--paper` の文字 |
| 地 | 既存のくぼみ色を90%不透明で使用 |

## 振る舞い

- 正面だけのときは正面図の右下、平面だけのときは平面図の右下に表示する。
- 選んだ側だけを表示し、上部の4択表示欄と同じ状態へ同期する。
- 両方表示に戻した場合は切り替えを隠す。
- 平面図の拡大ボタンは左へ逃がし、正面図の姿勢帯には右余白を確保する。
- ショーの配置データは変更せず、既存の表示状態だけを保存する。

## 検証記録

- 2026-09-13、アプリ内ブラウザで正面1枚表示にし、正面パネル右13px・下13px（枠1pxを含む）へ115×44pxの切り替えが表示されることを実測した。各ボタンの高さは36px。
- 右下の「平面」を押すと上部の表示欄も`plan`へ同期し、平面パネル側の切り替えだけが表示された。選択状態は「平面」だけ`aria-pressed=true`。
- 平面1枚表示では拡大ボタンとの間隔が13pxあり、互いに重ならないことを実測した。
- 添付スクリーンショットで縦長になっていた平面図の＋／−は、幅・高さ・最小寸法を44px、余白を0に固定した。更新後のアプリ内ブラウザで両方とも計算後44×44pxを実測した。
- `both-front`へ戻すと正面・平面が両方開き、右下の切り替えが0個になることを確認した。確認後の表示は両方①へ戻した。
