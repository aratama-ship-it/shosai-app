# 舞台スケッチ — 3Dモード入口

- 作成: 2026-09-13 / Codex
- 対象: 上部の作業モード列と、既存3Dカメラの起動・終了状態。
- 目的: 「通常モード」「タイムラインモード」「3Dモード」を同じ階層で選べるようにし、中央の作図道具から3Dだけが離れて見える状態を解消する。

## 継承する値

| 項目 | 値 |
|---|---|
| モード列 | `display:flex` / `gap:4px` / 左余白 `16px` |
| 各モード | 最小高さ `44px` / 左右余白 `18px` / 文字 `13px` / 行高 `1.5` |
| 選択中 | `--stage-timeline-text` / `700` / `rgba(211,172,89,0.08)` |
| 選択線 | 高さ `2px` / 左右 `8px` / `--stage-timeline-accent` |
| 角丸・影・動き | 既存タブを継承 / 追加なし / 追加なし |

## 状態と操作

- 並び順は、通常モード → タイムラインモード → 3Dモード。
- 3Dモードは既存の全画面3Dカメラを開く。3D描画・視点・編集機能は変更しない。
- 3Dを開いている間だけ3Dモードを選択中として表示し、通常／タイムラインの選択表示を外す。
- 3Dを閉じたら、直前に開いていた通常／タイムラインへ選択表示を戻す。
- 中央の作図道具列にあった短い「3D」ボタンは削除し、同じ入口を二重に置かない。
- iPad PWA・スマホ閲覧・習作レンダラーでは、既存どおり作業モード列ごと非表示にする。
