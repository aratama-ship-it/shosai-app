## 0. コンセプト1行

紗幕は素材ではなく**切り替え**である。同じ面が絵にも窓にもなることを、1本のつまみと場面送りだけで見せる。

## 1. 配色

UIに新色は足さない。既存 `style.css` のトークンだけを使う。
**新しい値は図の中（canvas）の3色だけ**で、どれも布そのものの色。

**★ 紗の地を明るくしない理由（試作で確認した失敗）**
最初に白紗を `#d8d2c4`（実際の生成りの色）で置いたところ、映していない余白（レターボックスの左右）まで
光り、**投影ではなく「光る白い壁」に見えた**。紗幕を明るくしているのは布ではなく投影そのものなので、
地は暗いまま置き、**絵だけが光を持つ**。白紗と黒紗の差は「地の色」ではなく「投影をどれだけ受けるか」
（§2 の `blackImgFactor`）で表す。

## 2. 透け（`sheer`）と不透明度の写し方 ← 本機能の中心

`sheer` は 0〜100 の整数。**0＝映す（面）／100＝透かす（窓）**。`s = sheer / 100` とする。

| 描くもの | 不透明度 | s=0 | s=50 | s=85 | s=100 |
|---|---|---|---|---|---|
| 紗の地（遮り） | `0.10 + 0.82·(1−s)` | 0.92 | 0.51 | 0.22 | **0.10** |
| 映す絵・映す言葉 | `0.95 · clamp(1 − s/0.85, 0, 1)` | 0.95 | 0.39 | **0.00** | 0.00 |
| 織り目（きめ） | `0.03 + 0.10·(1−s)` | 0.13 | 0.08 | 0.045 | 0.03 |
| 吊り元の線 | `clamp(0.35 + 0.50·(1−s), 0.35, 0.85)` | 0.85 | 0.60 | 0.425 | 0.35 |
| 黒紗のとき、映す絵に掛ける係数 `blackImgFactor` | `×0.55` | | | | |

**両端で 1.0 / 0.0 にしない。** 実物の紗幕は、映していても裏の強い光は抜けるし、透かしても紗は残る。
`s=0` で完全不透明にすると「紗幕である」という情報が絵から消え、`s=100` で完全透明にすると
「まだ吊ってある」ことが消える。**0.92 と 0.10 が下限・上限。**

**映す絵は紗の地より先に飛ぶ**（絵は s=0.85 で消え、紗は 0.10 まで残る）。
実物で前明かりを落としていくと絵が先に飛び、紗の地が少し遅れて沈むため。

### 状態の呼び名（つまみの目盛りの札・図の見出し）

| 範囲 | 呼び名 | en | zh-Hans / zh-Hant |
|---|---|---|---|
| `sheer ≤ 12` | 映す | Project | 投影 / 投影 ※NEEDS_REVIEW |
| `13 〜 87` | 渡り | Between | 过渡 / 過渡 ※NEEDS_REVIEW |
| `sheer ≥ 88` | 透かす | See through | 透视 / 透視 ※NEEDS_REVIEW |

目盛りの札（0／50／100）は**押すとその値へ飛ぶ**。連続量のまま置くと、現場で使う3つの言葉が画面から消える。

## 3. 描く順と幾何

### 正面図（客席から見る）— 中心体験

奥から手前へ。並べ替えは既存どおり駒の奥行き `v` だけが決める（`drawStage` の
`sort((a,b) => effectivelyPlacedPiece(a).v - effectivelyPlacedPiece(b).v)`）。**層を管理する画面は作らない。**

紗幕1枚の中は、この順に重ねる（順を変えると投影に見えなくなる）:

1. **紗の地** — 面の矩形を `SCRIM_WHITE`／`SCRIM_BLACK` で塗る（遮り）
2. **映す絵** — 縦横比を保って面へ収める＝**レターボックス**（引き伸ばさない。余白は地のまま）
3. **映す言葉** — 既存 `screenTexts` と同じ描き方。縦書きは一字ずつ下へ積む
4. **織り目（きめ）** — 格子。**これが「紗幕である」ことを言う唯一の視覚要素**（切ると半透明の板になる）
5. **吊り元** — 上端4px の線

| 値 | 数値 | 備考 |
|---|---|---|
| 織り目の間隔 | **8 内部px**（表示 約3.2px） | 5px にすると縮小時にモアレが出た（試作で確認） |
| 織り目の線幅 | 1px・格子（縦横） | 斜めにしない（回転で破綻する） |
| 吊り元の帯 | 4 内部px | |
| 既定の位置 | `v = 0.94`（前幕 0.96 のすぐ奥） | 「一番客席側」。中割りに吊るときは任意の `v` |
| 既定の寸法 | `w = venueSize().width`（間口いっぱい）・`h = 8m`・`lift = 0` | 既存の幕の既定をそのまま使う |

### 平面図（真上から）

真上からの図に透明度は描けない。**線種が「透ける膜」を言う。**

| | 既存の幕 | 紗幕 |
|---|---|---|
| 線 | 太線 **7px** 1本 | **細い二重線**（2.5px ×2本、中心から ±5 内部px） |
| 意味 | 向こうが見えない布 | 向こうが見える膜 |

- `sheer < 85` のとき、**客席側へ短いひげ**を出す＝いま映している。`--rust-ink`・長さ15px・間隔96px・
  不透明度 `clamp(1 − s/0.85, 0, 1)`。
- **平面図では「いま映しているか」だけ分かればよい。** 透け具合の連続量は正面図で見る。
- 幕の札は右外に `紗幕A　透け0%`。

### FPV（3D一人称）

- 紗の地・織り目は既存の `parts` の `tint`（`ctx.globalAlpha = clamp(tint, .12, 1)`）に乗せる。
- 映す絵は面の4頂点を投影し、**三角形2枚のアフィン分割で `drawImage`**（canvas 2D にパース補正テクスチャが
  無いための既知の近似。歪みは許容）。**紗幕は間口いっぱいで客席カメラはほぼ正対するため、正面席では歪みは出ない。**
  袖寄りの席では歪む。
- 面の法線が視点の向こうを向くとき（裏から見たとき）と、4頂点のいずれかが near 面より手前のときは**絵を描かない**。
  裏から見た紗幕は、地と織り目だけ。

## 4. つまみ（インスペクタ）

既存の「開き」のすぐ下へ**1行足すだけ**。新しい箱・新しい開閉を作らない。

```html
<label class="stage-control-label stage-range-label" for="stage-piece-sheer">透け <span id="stage-piece-sheer-value">0%</span></label>
<input type="range" id="stage-piece-sheer" min="0" max="100" step="1" value="0">
<div class="stage-range-scale"><span data-v="0">映す</span><span data-v="50">渡り</span><span data-v="100">透かす</span></div>
```

| 値 | 数値 | 由来 |
|---|---|---|
| ラベル | 10.5px `--milk-dim` | `.stage-control-label` 既存 |
| 値の表示 | 11px `--milk`・`font-variant-numeric: tabular-nums` | 既存 |
| 目盛りの札（新規クラス `.stage-range-scale`） | 9.5px `--milk-dim`・上マージン 1px・左右両端揃え | `.stage-cast-hint` の大きさに合わせる |
| つまみの高さ | 18px（`input[type=range]`） | 既存 |
| 操作対象の実寸 | つまみ本体はブラウザ既定。**目盛りの札は上下 6px の余白を含めて 22px 以上**にする | iPad で押せる大きさ。44px は取れないので札は補助（本体のつまみで操作できる） |

- `accent-color: var(--brass-lit)`（#d3ac59）。既存のつまみと同じ。
- 「開き」と「透け」は**別物**（開き＝布を引く／透け＝見え方）。両方出す。

## 5. モーション

**新しいモーションを一切足さない。** 既存の場面送りにそのまま乗せる。

| | 値 | 出典 |
|---|---|---|
| 場面送りの長さ | `sc().cueSeconds × 1000`、無ければ `state.sceneAnimMs` 既定 **2000ms**（200〜3000でclamp） | `stage-sketch.js` 18264行 |
| イージング | `t < .5 ? 4t³ : 1 − (−2t+2)³/2`（cubic in-out） | 同 18088行 `easeInOut` |
| 補間のされ方 | `MACHINERY_ANIM_KEYS.curtain` に `sheer: 0` を足すだけで、`piece.animMech.sheer` が線形に補間される | 同 18327〜18335行 |

**これが本機能の一番の見どころ。** 透けを機構値にすると、場面1（映す）→場面2（透かす）を送るだけで
「絵→窓」が**追加のアニメーション実装なしで**再生される。

- `prefers-reduced-motion: reduce` は本体の既存の扱いに従う（本機能では新規に分岐を作らない）。
