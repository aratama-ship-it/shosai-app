# 環境設定：パネル表示とiPad表示モード（2026-09-11）

## 目的と範囲

作図面を中心に保ったまま、端末ごとにパネルを「2列」「1列・左」「1列・右」へ切り替えられるようにする。iPad表示モードは、すでに使える左アイコン列と引き出しをそのままブラウザ表示にも適用する。ショー内のパネル内容、2列用の配置、ドラッグによる並べ替えを消さない。

## 操作

- `パネルの表示`で`2列表示`／`1列表示`を選ぶ。1列のときだけ`左側`／`右側`を選べる。
- 1列のドラッグ順は端末設定として別に記憶する。2列へ戻したときは、もとの左右配置を使う。
- `iPad表示モード`をONにすると、再読み込み後に既存iPad用の左アイコン列と引き出しを使う。OFFも同じ設定から戻せる。
- 実機iPadのPWAでは、このモードは常時ONとして扱う。

## トークン

| 要素 | 値 | 理由 |
|---|---:|---|
| 2列の間隔 | 18px | 既存の左右パネルと作図面の呼吸を維持する。 |
| 1列の間隔 | 18px | 空の列を残さず、同じ余白を作図面へ返す。 |
| パネル幅 | 240–480px | 既存のリサイズ範囲を保ち、長い日本語ラベルと図面を両立する。 |
| iPadの操作面 | 48px以上 | 既存のiPadドロワーの指操作サイズを再利用する。 |
| 表示切替 | 即時 / iPadのみ再読込 | 1列・2列はDOMを保ったまま切替。iPadは同じ操作子をドロワーへ移すため、安定した起動時切替にする。 |

## 確認条件

- 1列時は、全パネルが選んだ片側だけに並び、反対側の空白列を残さない。
- 2列へ戻すと、既存の左右配置が復元される。
- 各表示でもパネルの見出しをドラッグして順番を変えられる。
- iPad表示モードでは、アイコンを押すと左の引き出しが開き、正面図・平面図は右側へ残る。
- ブラウザ幅の確認と実機iPadでの確認は別とする。

## 2026-09-12：iPad上部アイコンと初期配置へ戻す操作

- iPad上部の「設定」「全画面」は、端末フォント依存の `⚙` / `⛶` をやめ、既存と同じ `viewBox 0 0 16 16` のインラインSVGを使う。表示20px、操作域44×44px、線幅1.35px、色とフォーカスは既存値を継承する。
- iPad上部の共有入口は44px枠内の「共」一つとする。演者用リンクは共有パネル内へ統合し、上部へ重複した入口を置かない。
- 共有パネル内のリアルタイム共有と演者用リンクは、同列の文章区切りにせず、外枠・背景・14px内側余白を持つ独立ボックスとして縦に並べる。リアルタイムは真鍮色、Viewerは青 `#81bfd4` の上端2pxで用途の違いを示す。
- 環境設定に「パネル配置を初期状態に戻す」を置く。通常色の既存ボタンを使い、全消去の危険操作とは罫線で分ける。
- 戻す範囲は、現在ショーの左右位置・順番・開閉と、この端末のパネル幅・1列/2列/iPad表示スタイルだけ。ショー内容、他ショー、スキン、言語、機能ON/OFFは変えない。
- 一度の確認後に実行し、保存完了を待って再読み込みする。全データを消す既存の「設定をリセット」とは文言・色・確認回数を分ける。
