# 舞台スケッチ — 出るものの種類3分類

- 作成: 2026-09-13 / Codex
- 対象: 「出るもの」パネルの追加入口、一覧見出しと、分類ごとの登録モーダル。
- 目的: 最初に「演者」「大道具」「小道具」を選び、その対象に必要な種類・名前・姿勢を一つの登録フローで決める。

## 状態と操作

- パネルの最初に3つの分類ボタンを均等幅で横並びにする。名前欄・種類欄・追加ボタンはパネルへ常設しない。
- 一覧見出しも登録入口と同じ「演者」「大道具」「小道具」に分ける。大道具・小道具は独立した一覧と高さ変更用の取っ手を保つ。
- 分類ボタンを押すと登録モーダルを開く。「演者」は名前＋姿勢、「大道具」は名前＋既存の舞台セット種類、「小道具」は名前＋形を同じ窓で選ぶ。
- 演者の姿勢は既存の姿勢一覧を使い、窓を開いた時の既定を `stand`（立つ）にする。
- 大道具の種類と演者の姿勢は、タイルを押した時点では窓を閉じず選択状態だけを更新する。「追加」を押した時に登録して閉じる。
- 姿勢・大道具・小道具のタイルは、ダブルクリックすると現在の選択をそのまま登録する。名前欄が空なら既存の自動命名を使う。
- 「小道具」は既存の7分類を見出しとして残し、各分類内を大道具と同じ絵付きグリッドで表示する。既定は `box`（箱）で、押した時点では登録せず選択状態だけを更新する。ディアボロは専用の向き・持たせる機能を保ったまま、「手に持つもの」へ表示する。
- 小道具の見本は既存の `PROP_SHAPES` の寸法・部品を描画し、実際に置かれる形と選択時の絵を同じデータから作る。「組んだセット」は既存のモデルセレクトを同じ窓の中で使う。
- 分類ボタンとタイルは、枠・背景・文字に既存の選択表現を使う。分類ボタンは `aria-haspopup="dialog"`、種類・姿勢は `aria-pressed` で状態を伝える。
- 既存の種類ID、登録データ、小道具の形、組んだセットの処理は変更しない。
- 「追加」は登録モーダルの下端に固定し、候補一覧だけをスクロールさせる。
- 「セットを組む」は一覧パネルには表示せず、大道具モーダルの下端左側に置く。既存のセットビルダーを開く処理を共用し、演者・小道具モーダルでは表示しない。
- 3分類すべてで候補名を検索できる。入力はNFKC正規化・大文字小文字を区別せず、空白で分けた語をすべて含む候補だけを入力中に絞り込む。
- 名前・色・検索は、各ラベルを入力の上に置いた同一行として表示する。色は名前の直後に置き、狭い固定列にする。
- 登録色は演者・大道具・小道具のすべてへ適用する。窓を開いた時は従来の自動配色を初期値に戻し、未操作の登録結果を変更しない。
- 演者・舞台セット・小道具の各一覧は別々に高さを変えられる。下端の取っ手をドラッグし、上下キーで20px（Shift時60px）ずつ調整、ダブルクリックまたはEnterで既定へ戻す。
- 平面図の「複数選択あり」は常設しない。複数選択機能と整列入口は残し、実際に2件以上を選んだときだけ選択件数を表示する。
- 手動の一覧高はショー内容ではなく端末の表示設定として保存する。上限は現在の一覧内容がすべて見える高さとし、一覧そのもののスクロールを消したい場合も外側のパネルスクロールへ移せるようにする。
- 検索は候補の選択状態・名前入力・登録データを変更しない。小道具では該当タイルが0件になった分類見出しも隠し、登録窓を開き直したときは検索語を空に戻す。
- 新しい色・モーションは追加せず、既存のカラーピッカー、検索入力、即時表示切替を使う。
