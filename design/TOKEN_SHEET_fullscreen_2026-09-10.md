# 舞台スケッチ — 全画面表示

- 2026-09-10 / Codex。本人指定: 「プレゼン」を「全画面」に改称し、Fキーを割り当てる。
- 既存の正面図の全画面表示を利用。ボタンとFで開始・終了、Escでも戻れる。
- 設定・案内・終了操作・通知を日英と中国語2種で統一。保存済み設定の内部キーは維持する。

| 項目 | 値 / 方針 |
|---|---|
| 上部ボタンのラベル | 全画面 |
| タブレットの記号 | ⛶（全画面の四隅） |
| ボタンの寸法・色・文字・余白 | 既存stage-langを継承、タブレットは既存44×44px |
| ショートカット | 修飾キーなしのF。長押し反復・IME変換中・文字入力中は無効 |
| モーダル・利用制限 | 開いているダイアログや非表示/利用不可の入口をショートカットで迂回しない |
| アクセシビリティ | aria-keyshortcuts=F、aria-pressedで全画面状態を同期 |
| 描画・字幕・解像度 | 既存の正面キャンバスと任意の説明表示を維持 |
| API非対応時 | 既存の画面内拡大を使い、F・Esc・終了ボタンで戻る |
| 追加モーション・依存 | なし |

デザインの数値は変更しない。表示文言・記号の収まりとキー操作の状態遷移を確認する。
