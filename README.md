# 制作の書斎（Phase 0 プロトタイプ）

ショー・演出リファレンスを、制作の問い・場面案・ビジュアル試作へつなぐ個人用の作業空間。

- メイン: **資料棚** — 作品データベースの閲覧（一覧・検索・詳細＋関連作品/関連表現の自動集約）
- サブ: **制作会社**（公式根拠つきの探索地図）／**名簿**（スカウティングレポートの演者名簿・要合言葉）／**制作机**（場面スタディ・ビジュアル比較）／**舞台スケッチ**（劇場形式5種・規模プリセット・正面/平面・PNG書き出し）／**スクラップブック**（種火を配る＋紙面へ貼って残す。自炊本25冊から変形した100件を含む）／**場面問答**（判断のエクササイズ）

## 名簿タブ（個人情報を扱う）

- データは**書斎側に置かない**。同一オリジンの `scouting-report-app/data/data.enc` を読み、合言葉で復号する。週次タスクでシートが更新されればこちらにも反映される
- 防御は画面を隠すことではなく**暗号化そのもの**（AES-256-GCM / PBKDF2-SHA256 15万回）。合言葉がなければ `data.enc` を直接落としても読めない
- 合言葉の端末保存キー `scout_pass` はスカウトアプリと共有する。どちらかで解錠すればもう一方も開く。**この共有があるため、書斎アプリへ外部スクリプト（CDN・解析タグ）を持ち込まない**
- `file://` では動かない（fetchがブロックされる）。名簿タブだけは公開URLから開く
- 名簿は読むだけ。ここから編集・追記はしない（元アプリとシートが正）

## 使い方

`index.html` をブラウザで開くだけ（静的・依存なし）。

舞台スケッチだけを使う場合は `stage.html` を開く。右列の「場面スタディ」から
「時をほどく研究室」の固定8ビートを別ショーとして開ける。各ビートは通常の場面なので、
配置・姿勢・メモを個別に直せる。元のショーは「ショー一覧」に残り、どちらもこのブラウザ内だけに保存される。

Vision Proの実寸・一人称稽古を拡張として統合する方針と、version 3から稽古用JSONへの変換契約は
[`docs/VISION_PRO_REHEARSAL_EXTENSION_HANDOFF.md`](docs/VISION_PRO_REHEARSAL_EXTENSION_HANDOFF.md) を参照。

iPad実機での通しQAは未実施（2026-07-28議論の優先度2位）。チェックリストは
[`docs/IPAD_DEVICE_TEST.md`](docs/IPAD_DEVICE_TEST.md)。

## データ

- `db.js` は正本データ（`../show-reference/data/*.json`、リポジトリ外）から生成した読み取り専用の索引
- `book-seeds.js` は自炊本の確認済み内容要約を出典にした、100件の未完成な一行場面。本文の転載ではなく、書名・分野・変形メモを持つ抽象化データ
- `stage-scene-study-data.js` は `../direction-knowledge/examples/time_lab_future_scene_study.json` から舞台スケッチに必要な固定項目だけを同梱したデータ。舞台スケッチは実行時に書斎・知識ベースを読まず、単独で動く
- 正本更新後の再生成: `python3 build_db.py`
- コード変更時は `index.html` 内の `?v=` を上げる（キャッシュ対策）
- **コード変更のコミットと、索引再生成のコミットは分ける**（履歴でコードの変更を追えるようにするため）
- 索引を何度も再生成した後は `git gc` で回収する（looseオブジェクトが溜まると .git が数十MBに膨らむ。gc後は全履歴込みで約5MB）

## 状態

Phase 0: 制作机と場面問答の内容は固定サンプル。舞台スケッチとスクラップブックはブラウザ内へ自動保存する。
舞台スケッチには、Codex／Claude Code共通のローカルMCPを追加した。AI案は直接ブラウザへ書かず、
`.stage-sketch-mcp/` の下書きと履歴へ残す。AI編集のJSONは、指示・概要・場面ごとの差分・警告を
読み込みモーダルで確認してから、既定の「別のショーとして開く」で元のショーを残したまま取り込める。
設定・使い方: [`mcp-server/README.md`](mcp-server/README.md)
AIによる既存ショーの編集を、差分確認・承認つきで進めるための実装前設計:
[`docs/AI_EDITING_HANDOFF.md`](docs/AI_EDITING_HANDOFF.md)
