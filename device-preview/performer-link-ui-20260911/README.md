# Stage Sketch performer-link device UI preview

This is a static, synthetic-data preview of the performer viewer for iPhone and iPad UI checks.

- Source sample: `public/ai-json/samples/sample-standard.json` (`四つの輪郭`, 8 scenes)
- Network mode: static UI only
- Personal notes: saved only in the current browser's local storage
- Share action: simulated success response; no content is submitted
- Search indexing: disabled with `noindex,nofollow,noarchive`

Rebuild from the repository root with:

```sh
node device-preview/performer-link-ui-20260911/build.mjs
```
